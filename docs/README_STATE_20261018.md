## 一、怎么跑（按顺序，别跳）

```powershell
cd C:\Users\wzh\Documents\trustscope

# 1) 换/烧比特流之前，必须先让 PL 变空白（否则面板会锁存成条纹）
cd ps_fft_dual
xsdb board_rst_system.tcl          # 先选 A9 目标，再 rst -system（PL 变空白）
xsdb stereo_bringup_byname.tcl     # 这一次会烧比特流 + 写 303 条传感器表 + 配 4 个 store

# 2) 之后只跑这个（不烧比特流）
xsdb ps_run.tcl

# 3) 看状态
xsdb ps_liveness.tcl
xsdb ps_probe_now.tcl
```

**硬规则（踩过血的）**
1. **不要在程序运行中重烧比特流**（`fpga -file`）——面板会锁存成条纹，只能冷启动恢复。
   要么冷启动后烧，要么先 `rst -system` 再烧。
2. `rst -system` **必须先选目标**（`targets -set -filter {name =~ "*Cortex-A9*#0"}`），
   否则报 `Invalid target`。而且**不要把它和烧录写进同一条命令链**——rst 失败后烧录照样会执行。
3. **屏异常时不要热插拔面板**。先试软件显示重初始化（`ps_display_reinit.tcl`），无效再整机冷启动。
