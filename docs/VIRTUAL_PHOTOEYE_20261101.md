## 1. 为什么放弃"中心闭环"

今天实测（2026-11-01，一次真实运行）：

```
centre 33.5  bbox 4..63      板子完全进画，正常推进
centre 49.0  bbox 21..77
centre 59.0  bbox 34..84
centre 54.5  bbox 39..70     ← 掩膜收缩 14 格（板没变小）
centre 72.0  bbox 43..101    ← 又增大 31 格
centre 122.5 bbox 110..135   ← 跳到板外的一个 blob（bx0=110，板右缘当时 ≈101）
→ 判"冲过头"，停在 122.5
```

**根因**：掩膜规则是"**逐格与陈旧静止背景比 > 24**"。皮带一动，皮带纹理/高光相对旧背景移动 → 掩膜在皮带格上乱跳；而 **bbox 是掩膜边界的 max 统计**，**一个杂散格就能把它拉到 110**。

**运动模糊不是原因**（算术否决）：模糊长度 = 48 px/s × 0.02 s = **0.96 px ≈ 0.12 格**。

**结论**：**运动中不能用连续估位**。换成"**一次过线事件 + 一次静止精修**"。

## 2. 触发门（四个门堵住今天的两种死法）

| 门 | 参数 | 堵住什么 |
|---|---|---|
| **前缘** | `bx1 ≥ 112` | 触发条件本体 |
| **尾缘窗口** | `30 ≤ bx0 ≤ 70` | **`122.5` 那次**——blob 的 `bx0=110` 出窗，不触发 |
| **pts 门** | `pts ≥ 300` | 掩膜收缩/blob 类的稀疏假象（整板 ~600–800，blob 只几十） |
| **持续性** | **连续 2 帧满足**（≈200 ms ≈ 1.2 格） | 单帧闪烁 |
| **武装条件** | **`bx0 > 5` 后才武装** | 进画阶段 `bx0` 卡在 1 是**截断相位**，不是真边 |

**尾缘窗口是关键**：blob 可以在任何地方出现，但"`bx0∈[30,70]` 且 `bx1≥112` 且 `pts≥300`"这个组合**只有真板子能摆出来**——和光电开关用"遮断面积"而不是"光强扰动"是同一个道理。

```python
TRIG_BX1 = 112      # 标定：跑一块板，手动停在 dx≈0，读静态 bx1，反写这个常数
PTS_GATE = 300
BX0_WIN  = (30, 70)
armed, consec = True, 0

# 每 100 ms（现有轮询器）
d = fast_state()
if armed and d['bx0'] > 5 and d['pts'] >= PTS_GATE \
   and d['bx1'] >= TRIG_BX1 and BX0_WIN[0] <= d['bx0'] <= BX0_WIN[1]:
    consec += 1
    if consec >= 2:
        link.stop(); armed = False
        # -> 静止精修
else:
    consec = 0
```

**触发后 `armed=False`，直到 `pts` 归零（板被取走）再重新武装**——防止同一块板重复触发。

## 3. 静止精修（精度的来源）

```python
# 停止后
time.sleep(0.5)            # 掩膜/位置读数就绪；1.1 s 与 8 s 是【判决】的表，不在这等
d = fast_state()
if d['reg'] == 1:
    off = d['dx'] / 128.0   # 1/16 px -> 格
else:
    off = 79.0 - (d['bx0'] + d['bx1']) / 2.0
if abs(off) > 3:
    run_for(abs(off) / 6.0)   # 6 格/秒；一步开环修正
    time.sleep(0.5)
# -> 判决（此刻配准天然对齐，年轻窗最快）
```

**触发瞬间 `bx1` 的抖动（±10 格）不进精度账**——停止后 0.5 s，皮带静止、陈旧背景重新匹配、掩膜可信，**此刻读 `dx`**（相关 argmax 对整板 artwork，比 bbox 抗噪两个量级）。**触发线只负责把板送进精修锥内。**

## 4. 三张时间表（不要混）

| 等什么 | 时长 | 为什么 |
|---|---|---|
| 运动模糊消失 | **1 帧（20 ms）** | 曝光 20 ms，停带后下一帧就是干净的 |
| **位置读数就绪** | **0.5 s**（1–2 个 PS 循环） | `LIVE_MASK` 是逐帧分割 |
| 判决统计就绪 | 1.1 s（8 帧均值）/ ~8 s（年轻窗） | **这是 darea/判决的 settling，与位置读数无关** |

**把后两行混为一谈，是这条路径之前显得不可行的原因。**
