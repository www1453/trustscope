## 0. 先声明这次对照**不是配对**的

| 项 | 今早（基线） | 现在（环光） |
|---|---|---|
| 照明 | 环境光 | 环光，调暗到另一半（`exp 4331`、`mean 368`、`clip 1‰`） |
| 曝光 | 钉 8662 | 钉 4331 |
| 背景 / 参考 | 旧光下取 | 已在新光下重取（`bg_cells 0`、cam0_ref 972 / cam1_ref 798） |

所以**跨会话的类别差不能直接比**（参考、曝光、光照全变了）。
可比的量是**每个会话内部的"零值 vs 信号"**：

- 零值 = **良品板 g7** 五次重摆的 `max_z` 最大值（板没毛病，读数全是噪声）；
- 信号 = **划伤板 d30** 五次重摆的 `max_z` 最小值（这是它能给的最小读数）。
- 判据用一个数：`separation = min(d30) − max(g7)`，**> 0 才算这个统计量能用**。

判定由 `dl\publish_20261030\skill\scripts\null_floor.py` 机械给出，不靠我读表。

## 1. 假设与预测（具体到数）

**H1（灯有用）**：低角度环光把镜面压掉、并在沟槽上产生掠射散射，使缺陷读数相对零值抬高。
若 H1 成立，应观测到：**`separation > 0`**，具体形态二选一——
- g7 的 `max_z` 从 1.533 降向 ≤1.30，或
- d30 的 `min_z` 从 1.100 升到 ≥1.55。

**H2（灯只改变几何，不改变可检性）**：两类读数仍然重叠（`separation ≤ 0`），
只有掩膜变大（**这一半已经测到**：cam0 ref 791→972、cam1 745→798）。

**每行的"不应观测到"**（区分力所在）：
- H1 不应观测到：两类区间仍然交叠；也不应观测到摆位散布本身**变大**（那是灯破坏了重复性）。
- H2 不应观测到：`separation` 翻正。

## 2. 能作废这次实验的条件（先写）

1. 任何一次摆位的门失败（`regwhy ≠ 0`、`diffok ≠ 1`、`mean` 出 150–780、`clip > MB_CLIP_LIME`）→ 那次重摆，不计入。
2. `d0.raw` 不是 28800 字节 / `tol0.raw` 不是 14400 字节 → 该次作废（自检已抓过一次"读一半网格"）。
3. 位姿通道若打印 `POSE WORD DEAD` → 图右栏不作数（201/202 是死字，已查实）。
4. 曝光/参考在一次会话内变化（`mean` 漂移 > 30‰）→ 该批作废。
