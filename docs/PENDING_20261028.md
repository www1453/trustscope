## 三、已解决但值得记住的坑（写进报告/技能包）

1. **曝光必须钉住**（`MB_EXP_LOCK`）：AEC 的带 150–780‰ 太宽 → 空皮带 329‰、有板 525‰ → 固定背景在两者之间作废（掩膜 5825 格）。
2. **背景必须在空皮带上采**，且采完立刻开始，中途不动灯。
3. **限值与参考帧绑定**：换参考，全部 DAREA 平移（实测同一块板 4 → 17）。
4. **A9 调试通路可缓存**：JTAG 写小数据可能停在 L1；读 DDR 的 logits 会读到旧值 → **信邮箱，不信原始缓冲区**。
5. **取参考后要等几秒**（AEC 的增益还在调），否则一致性检查会误拒。
