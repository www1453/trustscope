# 能力边界，写成产线分工 · 2026-11-01

> 一句话：本工位是**在线筛**，不是全检终判。它承担两类有数的缺陷；细划痕在它的光学采样里没有可分离信号，
> 这一类**明确划给人工复检工位或下游工序**，而本工位对它输出"无法判定"，**不输出假 OK**。

## 二、不在本工位光学采样能力内的一类：细划痕

四个方向都量过、都被否证，每一组都带分母：

1. **12 条统计量**：10-29 那批 12 块划伤板 **0/12**（**仅限值 8**；10-29 批在限值 6 下为 1/12 账本行、2/12 格点），良品 0/41–0/39。
2. **参考维度（多参考 / K 库）**：同一块良品板换 5 份参考，`darea` 在 **1 … 17** 之间动；同一批参考把污染板也一起推高、一起压低——共模，不能当选择杠杆。
   K=8 逐格 min 相对"库外选好的那一份单参考"只多 **0.2/21** 块（McNemar p=0.22），K=16 逐块相同（0:0），K=4 更差（0:36，p<0.001）。
3. **64/64 采样**：同一条 2 px 线，出厂统计量随相位在 **10 ↔ 20 灰**摆动，整格 64 像素恒定 **14–15 灰**——是相位平坦化，不是放大；在 30 灰判据下两种统计量都是 0 格。
4. **亚像素配准**：同一块板对自身，残差从 **33.2 灰**只降到 **30.0 灰**（目标 ≤10 灰）；0.37 px 位移就产生 **14.74 灰**、0.62 px 产生 **22.62 灰**——几何残差本身就等于划痕的信号量级。

→ 所以结论是**分工**，不是"原理上不可能"：要救这一类，换暗场/低角度照明或 ≥2× 放大，那是另一台设备的前提。

## 三、三值判决让这个分工安全

- 输出三值：`MB_DIFF_VERDICT`（字 222）= 0 PASS / 1 NG / **2 无法判定**。
  固件规则是"拒判一律 2，绝不是 PASS"——**拒绝从不计为通过**。
- 拒绝是**可数的产出**：主机侧扫描写 `refused=1 / ng=NA`、不投票（`2·N_g ≥ 限值` 时启用）；
  验收条件之一就是"12 块划伤**允许 0/12 输出 OK**"（10-31 交接 §6）。
- 于是下游只处理"被拒判"的那一格，而不必去猜"这一格是不是被漏掉了"。
  这就是把能力边界写成工序的理由：**本工位说"判不了"，产线才知道该把它交给谁。**
