## 二、必须记住的四条（都是这一轮的代价）

### ① I2C 总线与相机的对应（**已验证，别再猜**）
```
I2C0 (0xE0004000) → **左**相机（面板 LEFT CAM）   → CAM_LONG_L / CAM_SHORT_L
I2C1 (0xE0005000) → **右**相机（面板 RIGHT CAM）  → CAM_LONG_R / CAM_SHORT_R
判定方法：给两条总线设 6 倍差异的曝光，**哪个视图亮就是哪条** —— 一次实验定死
```

### ② 融合当前是关的，原因是它自己有 bug
```
开融合时：程序自报 long exposure at/over clip = 0 (0.00%)  ← 声称全恢复
实际画面：MEAN = 4（几乎全黑）                              ← 但画面全黑
⇒ 融合的算术有问题，不是参数问题
⇒ 而且它**每帧把 SHORT 档写给两颗传感器**，覆盖一切外部设置
⇒ 掉电重启后立即读 I2C0=690(=CAM_SHORT_L)、I2C1=0 就是这个原因
⇒ 想再试融合：先读 fuse 那段代码，别再看画面猜
```

```
主机写 10000        → 两路都读到 10000 ✓
```
