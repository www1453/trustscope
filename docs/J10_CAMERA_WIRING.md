## 计点

- 相机 0：**5 根信号**（10 数据 + PCLK + HREF + VSYNC + I2C×2 + 复位）
- 相机 1：**5 根信号**（同上）
- 两路合计 **10 根**，J10 共 34 个 IO ⇒ 放得下（其余 2 个 IO 不要接）
- **J10 只有 3 个 GND 脚** ⇒ 50 cm 每根信号必须自带一根地，全部回到这 3 脚

## 三条安全规则

1. **B20（相机0复位，输出）↔ V12（相机0 D0，输入）相邻，绝对不能互插**（`AGENTS.md` 明写）
2. **W14（相机1复位，输出）同为输出脚**，接线时按手册核对其相邻脚位
3. **断电接线 → 万用表逐脚核对 5V/3.3V/GND 与顺序 → 再上电；永不带电插拔**

## 50 cm 的附加要求

- 每根信号**双绞**配地；线长**互差 ≤2 cm**
- **相机端**每根信号串 **22–33 Ω**（板端已有 33 Ω 排阻）
- **PCLK 降到 ~10 MHz（≈7 fps）**：`fps = PCLK/(1892×740)`
- **连拍 3 帧取通过完整性检查的一帧**；`CHANTOT` 必须恒为 **691200**
