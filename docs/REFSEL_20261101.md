# 参考选择：离线挑一份、装上去、锁住（2026-11-01）

**一句话（E1/E2）**：只用档案里 41 块良品选参考，良品侧尾巴最小的是 **g6 = 0 格**（与 g17 并列 0），最差 g34 = 2 格，**极差 2 格**；g6 装上后限 8 的误杀 **0/40**。但**全部 41 个候选在限 8 都是 0/40**——这批良品上"挑参考"买到的特异度是 0。它**不能**提高划痕检出（任何判据都是 0.9–1.9/12）。

## 1. 判据（写死在 `dl/refsel_20261101.py` 头部，先于任何数字）
候选 r：其余每块良品对 r 求逐格 |Δ|，过固件自己的 **30 灰**地板，取 8 连通最大组 = darea；r 的**尾巴** = 这些 darea 的 **97.5 分位**（41 块良品时分位即最大值）。最小者胜，平手按 90 分位尾巴、再按逐格灰 97.5 分位破。**缺陷帧在 `select_reference()` 里根本拿不到**（只注册良品），这是"合法"而非"赢家诅咒"的唯一理由。

## 4. 操作步骤（操作员不用读代码；完整版 `--procedure`）
1. **采 K 块良品**（每个固件会话一次；同一盏灯，逐帧记 `MB_AEC_MEAN`(151)，偏离首帧 >5% 作废重拍），每块板一条命令：
   `python dl\host_qc\evidence.py --request --frames-dir dl\sweep_frames --session 20261101_station --label good1`
   它写 `<session>\<label>\frame.bin` **和 `mask.bin`**——两份都要，选择器要掩膜来定支撑。
   （`frames_20261031.py` 只写 `*.raw`、**没有掩膜**，拿它跑选择器会被拒绝：实测无掩膜时良品尾巴变成 247–397 格，量的是皮带不是参考。）
2. **离线选**：`python dl\refsel_20261101.py --offline --frames dl\sweep_frames\20261101_station` → 读 WINNER 与极差。**极差 ≤1 格就说明挑不挑一样**，别做仪式。
3. **装**：停核 → 2.7 MB 分 6×450 KB `dow -data` 进 **0x12400000** → `mrd` 回读逐字节比对（不等就停）→ `con` → `mwr -force [expr {0x10F00000+101*4}] 17`（**MB_CMD=17**）。现成工具（逐字节回读 + 年轻窗口都做好了）：把一行 `chosen|dl/sweep_frames/20261101_station/good1/frame.bin` 写进 `dl\_refsel_spec.txt`，再跑 `python dl\multiref2_bench.py sweep --spec dl\_refsel_spec.txt --restore 1`。
4. **等年轻窗口（~8 s）**：`MB_DIFF_OK`(180) 读 1、`MB_REG_STATE`(232) 读 1、`MB_DIFF_DAREA`(23) 不再是 0xFFFFFFFF。窗口关掉之前读到的行属于**上一份**参考（11-01 每次安装的第一行都复现上一次的 darea：62→0→5→4）。
5. **锁 + 记**：`--verify` 复核，把 `MB_PART_REF`、`MB_DIFF_DAREA` 写进班次日志。**任何固件变化后重做 1–5**：参考只在**同一个固件会话内**有效——bring-up 重写 303 条传感器表，AEC 工作点 8662→2105，而帧均值只从 509 到 501‰（亮度闸门看不出来）；同一块墨污板，装恢复前那帧读 13,14,13,13,13，装恢复后新拍的读 0,0,0,0,0（E2）。

## 5. 买到什么 / 没买到什么（E1/E2）
- **买到的**：一条可在本班次内测出来的"参考是否值得挑"的判据，和一个 0 误杀的安装点。**没买到的**：本档案上它换不到误杀（41/41 都是 0/40）；也**不能**提高划痕检出（0.9–1.9/12，所有规则一致）。
- **为什么和 11-01 现场不矛盾**：现场同一块良品对 5 份参考读 darea **1→17**（极差 16 格、同板重放地板 4 格，E2）——那是**固件尺度、且候选是 5 块真不同的板**，尾巴已经顶到/越过限 8，挑参考当然有用；本档案 41 块良品尾巴 ≤2 格，离限 8 有 8 倍余量，所以挑不出来。**结论：参考选择只在尾巴接近限值时才值钱，而那种情形必须先量出来**。
- **未测（E0）**：离线帧路线的排序能否搬到固件的配准上（档案只存了一份参考的固件网格，无法对第二个候选做 E2）；缺角 n=2、划痕 n=12 的人群结论；g20/g37 的配准残差如何进入尾巴。
