# 预注册 — 收窄视场（OV5640 1:1 裁剪 2×）是否提高划痕的类别分离度（2026-10-31 18:2x 冻结）

> 冻结时**没有任何裁剪模式的图像**，也没有它的背景/参考。当前配置：
> 构建 TSC1EDC634BF、曝光钉 4331、环光开（调暗一半）、`MB_PART_RULESEL=1`（背景规则）。
> 判据沿用今天一直用的那一个数，不新造统计量。

## 0. 为什么是这件事

今天已经被否掉的：融合/AND（预注册判据 −0.500，且独立视角上限 1.60×）、提亮 cam1（k=3 削顶 118‰）、
子格最大值（峰值收回 1.95× 但 AUC 0.5）、EG（良品比划伤更高）、8 帧平均（已在做）、
格级调参（十次）、颜色四色点（STAGE_Q）。**还没被否证的物理杠杆只剩"提高采样密度"这一个。**

**机会**：OV5640 现在是"读全阵列 2624 → ISP 缩到 1280×720"（今天实测：`x 0..2623`、输出 1280×720、
ISP step 0）。改成 **1280×720 的 1:1 窗口**即在**不换镜头**的前提下把采样密度翻倍。

## 1. 假设与反向机制（两个都要写在判据里）

**H1（放大有用）**：格覆盖从 0.4 mm 降到 0.2 mm，一条 1–3 px 的划痕在一格里的占比翻倍，
缺陷响应按 ~2× 上升，而良品侧的**纹理**项不变 → `separation` 翻正。

**H1 的反向机制（必须一起测）**：今天量到良品侧残差**由摆位主导**（重摆散布 0.63，是类别差的 3 倍）。
摆位误差在毫米上是常数，在**格**上会随放大翻倍（0.5 mm：0.4 mm/格 → 1.25 格；0.2 mm/格 → 2.5 格）。
所以放大会**同时**把良品噪声抬 ~2×。若两者同倍缩放，`separation` 不变。

**判据必须能分开这两条**：不能只看缺陷响应是否变大。

## 2. 统计量与判据（看数之前写死）

对每块板取**同一个统计量**：`max |d| / 该格容差`，判格上（与今天 `place_area` 完全同源代码路径）。

- **零值** `N` = 3 块良品（`g7`、`g1`、`g22`）各自 3 次重摆的 `max_z` 最大值；
- **信号** `S` = 3 块划伤（`d30`、`d23`、`d32`）各自 3 次重摆的 `max_z` 最小值；
- **主判据**：`separation = S − N > 0`。
- **反向机制的判据（附加、必须先看）**：放大后**良品的重摆散布**（同板 3 次的极差）相对当前
  （g7 五次 0.633）是否也翻倍。**如果散布翻倍而 separation 没翻正**，判 H1 被推翻，且原因是摆位。

## 3. 作废条件（写在这里，跑完不许改）

1. 裁剪后图像的 `mean`/`clip` 出 AEC 带（150–780 / clip > 10‰）→ 先修曝光，不计入。
2. 裁剪后 `cam1` 的 `refq ≠ 0` 或两路 `diffok ≠ 1` → 该次重摆。
3. `d0.raw` ≠ 28800 字节、`tol0.raw` ≠ 14400 字节 → 该次作废。
4. **视野只剩四分之一** → 若某块板在裁剪视野里放不下（`part_edge` 或 `inview=0`），该板记为
   "not measurable at this field of view"，不许用"放不下"当作"检不出"或"检得出"。
5. 裁剪后必须**重采背景与参考**（新几何是新的会话量）；沿用旧的 → 整批作废。

## 4. 样本与次序

**6 块板先跑**：3 划伤 + 3 良品，每块 3 次重摆 = 18 次快照（用 `place_area --run --mode hand --tag mag`）。
次序：先 3 块良品，再 3 块划伤（避免操作者疲劳偏向某一类）。

## 5. 判定与后续

| 结果 | 结论 |
|---|---|
| `separation > 0` 且良品散布未翻倍 | 放大有效 → 值得做分块拼接，并重扫人口 |
| `separation ≤ 0` 且良品散布翻倍 | **H1 被推翻，且机制是摆位** → 放大的收益被摆位噪声吃掉，要先解决摆位（或注册判据）再谈放大 |
| `separation ≤ 0` 且散布未翻倍 | 放大的收益不足以拉开两类 → 采样密度不是这一类的解，回到"光学/照明" |
