# 2026-10-31 — 同板重摆的散布 vs 类别差：手放板这一项比缺陷本身大

> 一句话：**同一块板放十次，残差的最大值跳动 0.23–0.57 z；而 26 块板上划伤类与良品类的差是
> 0.20 z（按最大值）或 0.01 z（按均值）。** 摆位这一项的方差大于类别差本身，
> 所以任何作用在同一残差上的统计量（脊线、色度、按长度判定）都会被它淹没。
> 顺带查实：**`MB_DIFF_DX/DY`(201/202) 在这版固件里从来没有被写过**，`main.c:2240` 的注释是假的。

## 1. 为什么做这个

今天被否掉的每个统计量都呈现同一个特征：**良品类在它们上面分数更高**（8×8 均值 51.6 vs 89.1 灰、
EG A 123.5 vs 127.9、EG B 178.4 vs 188.0，都是划伤 vs 良品）。统计量不能为这个负责——
除非"板每次放得不一样"这一项本身就比"缺陷改变了画面"大。这一项项目**从未用固件自己的配准量过**，
而且**不能从帧里补**：离线拟合 4 参数相似变换后残差 60–100 灰，固件自己配准后是 5–30 灰
（差 3–4 倍），离线这层永远复现不了固件的配准精度。

## 2. 方法（E2）

`python dl\place_area_20261031.py --run`：**g7（良品）× 5 次、d30（划伤）× 5 次**，
每次抬起、**刻意挪 2–5 mm** 再放下、按回车；每次一拍核停快照（`d0/d1/tol0/tol1/mask0/mask1` + 字表）。
统计量取 `max |d| / 该格自身容差`（判格上），也就是与预注册分析同源的那个 z。

## 3. 结果

| d30_r2 | 划伤 | 1.100 | 423 | 480 |
| d30_r3 | 划伤 | 1.233 | 423 | 497 |
| d30_r4 | 划伤 | 1.400 | 419 | 503 |
| d30_r5 | 划伤 | 1.267 | 423 | 470 |
| g7_r1 | 良品 | 1.367 | 419 | 496 |
| g7_r2 | 良品 | 1.367 | 423 | 437 |
| g7_r3 | 良品 | 1.300 | 419 | 486 |
| g7_r4 | 良品 | 1.533 | 419 | 509 |
| g7_r5 | 良品 | 1.333 | 419 | 470 |

```
同板散布（摆位项）:  d30 1.100..1.667  range 0.567
                     g7  1.300..1.533  range 0.233
26 块板的类别差:     max z  良品 1.03 / 划伤 0.83   -> 差 0.20（且方向是良品更高）
                     mean z 良品 0.158 / 划伤 0.168 -> 差 0.01
```

**摆位项 / 类别差 ≈ 1.2–2.8 倍（按最大值）、20–50 倍（按均值）。** 同板重摆的跳动比
"两类板之间的差"还大，而且方向随机——这解释了今天所有统计量为什么都失败。

**不是灯的问题**：`bright` 十次全是 256，`mean0` 只在 419..423 之间动（4‰≈1 灰）；
而 `judged` 判格数在 437..509 之间动（±7%）。所以跳动的来源是**几何/局部**（配准的亚像素残差、
或手挡光的局部阴影），不是全局光照漂移。

## 4. 一处查实的死字（E2）

`MB_DIFF_DX/DY`（201/202，词表里写着"registration shift, 1/16 SOURCE pixel"）
在这十次摆位里**读到的都是 580、dy 都是 0**，跨板都不变。全文 grep：这两个字**从来没有被写过**，
只有 `MB_ALIGN_DX/DY`(226/227) 被写 0、`MB_REG_SCALE`(231) 被写 256。

- `main.c:2240-2241` 那句"位姿发布在 226/227 与 201/202"**与代码不符**；
- 任何按词表读 201/202 当位姿的主机都会拿到 DDR 里的陈旧数；
- 所以这一轮的**位姿通道**（图的右栏）是空的。工具的 `--analyse` 现在自带一条零检验：
  位姿字在多次摆位里完全不变就打印 `POSE WORD DEAD`。

## 5. 结论：杠杆要换方向

| 杠杆 | 现在还成立吗 |
|---|---|
| ② 脊线/沿线匹配滤波 | **不成立**：作用在被摆位噪声主导的残差上 |
| ③ 色度残差 | **不成立**：同上 |
| ⑥ 按长度判决 | **不成立**：同上 |
| ⑤ 参考多帧平均 | 低价值：它减的是参考侧噪声，而这里的噪声在活帧侧（摆位） |
| ④ 交叉偏振 | 仍成立，但理由变了：它减的是镜面/高光这一类**局部**残差 |
| ⑦ 收窄视场/提高像素密度 | **仍是最强的一条**：把缺陷从 1–3 px 抬到 2–6 px |
| ⑧ 低角度环光 | 仍成立 |
| **⑨ 机械重复性（夹具/定位槽）** | **新增，且现在排第一**：它直接减掉这一项方差，而这一项今天量出来比缺陷还大 |

⑨ 值得单说：既然手放的重复性是 0.23–0.57 z 而缺陷是 0.20 z，
那么**一个能重复到 0.5 mm 以内的定位槽，可能比换镜头更便宜、更快地让现有的统计量开始工作**。
这与报告里"没有自研夹具"那句是同一个事实的代价面，之前只写了代价，没有量。

## 6. 边界

- 只有两块板 × 5 次，是**校准**，不是人口统计；不能据此说"划伤一定检不出"，
  只能说"在当前摆位噪声下，这一类的信号被淹没"。
- 十次摆位是同一个操作者、同一间屋、同一次会话。换人或换时间，这一项的数值会变。
- 位姿通道是空的（§4），所以**无法**把这一项进一步拆成"平移/旋转/尺度"各占多少。
