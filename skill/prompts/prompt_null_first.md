# 提示词工作流 · 在花掉样本之前，先让模型写下"这次测量会怎么失败"

> **任务形状**：你准备采一批数据来定一个阈值 / 验证一个改进。你**还没有**采。
> 这是唯一一个"成本几乎为零、收益最大"的时刻。
>
> **本项目的代价**：两个新判据实现完之后，一个 54 个工位的验收计划已经写好。
> 第一个工位（参考板对自己）读出轮廓面积 **141/150/149**，与内极差 **44–80**；
> 而它们要抓的角缺是 **3–4 格**、划痕最大 **11**。**天花板在信号上面。**
> 五十个工位不会比第一个多说什么。见 `../pitfalls/measurement-traps.md` M53。
>
> 这条提示词就是把那个下午换成两分钟。

---

## 提示词原文

```
我要做一次测量，现在还没有采数据。请在设计之前帮我写"它可能怎么失败"，
不要给鼓励，不要给乐观的解释。

我的计划：
  测量的量：<统计量是什么、怎么算的、分母是什么>
  缺陷（或要检测的现象）：<是什么、大概多大/多快/多亮>
  我打算采的样本：<对象、数量、每个样本几次重复>
  我打算用它做的决定：<阈值？验收？开关一个功能？>

请按下面四段输出：

1) NULL 的设计
   "同一对象、同一条件、正确答案已知为'无缺陷'"的那次测量具体怎么做？
   （写成一个可执行的动作，不是"做个对照"。）

2) 如果这次测量的地板高于信号，会读到什么数？
   给出一个数量级估计，并说明你的估计依赖哪个假设。

3) 三个可能让这次测量白做的原因，按"白做的代价"排序。
   每条写：怎么在**不采 population** 的前提下发现它。

4) 一个"杀死这个判据"的判据（kill criterion）：
   在什么读数下，我们应当停止这个测量并改设计，而不是继续采样本？

不要建议"多采一些样本会更稳"——样本量不能把地板压到信号以下。
```

---

## 为什么这样问（三段设计）

| 段落 | 防的是什么 |
|---|---|
| 1) NULL 的设计 | 模型默认会把 null 理解成"对照组"，而**同一块板对自己**才是真 null |
| 3) 三个白做的原因 + 排序 | 强迫它按**代价**排序，而不是按"听起来严重"排序 |
| 4) kill criterion | 这是唯一能**在执行中途**停下来的东西；没有它，采样本的人不会停 |

**最后那句"不要建议多采样本"是必要的**：模型的默认安慰是"样本更多更可靠"，
而这次失败的形状恰恰是"样本再多也没用"。

## 真实案例（这就是它被写出来的原因）

```
实现：两个判据（轮廓面积、单元内极差），publish-only，不参与判决
计划：54 个工位 × 3 档阈值 × 每档若干次比较，用来定阈值
实际：第 1 个工位（参考板对自己）就给出
        轮廓面积 141 / 150 / 149   （它要抓的角缺：3–7 格）
        单元内极差 44 / 80 / 49     （它要抓的划痕：最大 11）
      修好之后：轮廓 825（比参考掩膜本身 766 还大）、极差 20（中位好了，尾部 132 更坏）
结论：两个统计量在 population 之前就死了。计划作废。
```

**如果当时问了这四段**：第 2 段会逼出一个数量级估计（"角缺只有几格，而边界量化
抖动是几十格"），第 4 段会给出 kill criterion（`max(null) >= 已知缺陷读数 ⇒ 停`）。
这两条中任何一条都能省掉整轮计划。

## 失败案例

1. **模型把 null 设计成"两块同型号的板子"。** 那不是 null：摆位、光照、个体差异全部
   混进来了。**判据**：null 的定义里必须出现"同一个对象"和"正确答案已知为无缺陷"。
2. **模型给出"建议先做小规模试验"就结束。** 这是空话，不是设计。**判据**：
   第 1 段能不能直接照着做？不能就是没写。
3. **kill criterion 写成"如果效果不明显就停"。** 不可执行。**判据**：
   有没有一个数？没有就不是判据。

---

## 适用 / 失效条件

- **适用**：任何"先采数、再定阈值"的测量；任何"这个优化有没有用"的 A/B；
  任何验收计划（尤其是要花人工摆位的那些）。
- **失效**：探索性测量（你还不知道要找什么）—— 那时应该先做**定性**观察，
  而不是先写 kill criterion。但一旦你开始"用这批数做决定"，就必须回来补这一节。
- **失效**：null 在物理上无法构造（例如"同一时刻只能测一次"的一次性事件）。
  此时改为**两个独立手段交叉验证**，并在报告里写明为什么 null 构造不出来。
