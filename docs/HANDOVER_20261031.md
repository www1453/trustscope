## 二、今天的七条技术结论（全部实测，可直接写报告）

1. **掩膜地板修复**（cam0 常数 400 → `clamp(ref/2,64,400)`）：d23 从**永远拒判**变成**两路都判**
   （`diffok` 5→1、`fvalid` 0→350）。五块良品回归**零翻转**。
2. **固件 AND 门原来用常数 400 对两路** → 算术上不可达；改成逐路地板后 **`and_ok = 1`（本项目首次）**。
3. **但 `and_cells = 0`、`and_ovl = 0`**：两路一格都对不上。**几何是唯一剩余阻塞。**
4. **VTS 740 → 1200 生效**：cam1 的曝光上限 11,776 → 19,136（cam0 是 19,136 打平），
   其自身曝光 4331 → 8662。
5. **cam1 的掩膜只有 8–9 行高、恒定落在格行 51–59**，而板体在 cam1 里占 54–85 行。
   **原因不是 ROI**（ROI 只会造成 0.49–0.74 的比例，实测是 0.14），而是**亮度**：
   皮带亮度沿画面从 200 掉到 44（cam0）/ 145 掉到 18–23（cam1），
   **掩膜阈值 `BG_MASK_THR=24 是绝对对比度门**，cam1 的暗区里 |板−背景| < 24 → 掩膜在那里死。
6. **因此双视角合议的有效面积被钉死在 ≈324 格（2.3% 全网格）**：
   行交集 51–59（9 行）× 列交集 62–97（36 列）。**这是测出来的上限，不是没做成。**
7. **诊断字搬迁**：十个注册字从 418–427（落在 `MB_DIFF_ROW` 的 416–460 行均值带里）搬到
   640–649，加序号字 650。**这就是为什么 `why=1/2` 以前从来没读到过一致值**：
   行均值 1/2 与 `PART_OUT`/`NOCONV` 的码值无法区分。

## 三、**不要犯的错**（今天 17 次的归纳，按危险度排序）

### A. 读错了字（6 次，最贵）

| 现象 | 真相 |
|---|---|
| 我说 cam1 有 43% 削顶 | 431 是 **`MB_CAM0_MEAN`(212)**，cam1 的 clip 是 **`MB_CAM1_CLIP`(211)=0** |
| 我说 `MB_DIFF_MS`=word 152 | **152 是 `MB_AEC_STEPS`**；比较耗时的字另有其处 |
| 我说 `cam1_pts_c = W 615` | **615 是 `MB_V0_FRAME`（cam0 的掩膜重建计数器）**，不是 cam1 的格数；cam1 没有独立集群计数 |
| 我说 mean(151) 是亮度 | **它随曝光不变化**（1.9× 曝光它不动），不是"场景构成混合量"也不是亮度 |
| 我说掩膜在 2–5168 之间切换 | 那是**板子放/拿的转场窗口 + 停核快照窗口**里的读数 |
| 我说 `diffok=5` 是一个东西 | 它是**三个族**：`regwhy=6` YOUNG（7.3%，设计内去抖）、`2` NOCONV（8.5%）、`1` PART_OUT（4.1%）|

**规矩：任何"这个字是什么"的问题，先 `grep '#define MB_xxx'` 再读，不要凭记忆。**
`dl/host_qc/qc_mailbox.py` 是主机侧的词表，`ps_ui/main.c` 的注释是权威。

### B. 把一次会话的值当常数（5 次）

`400`（掩膜地板）、`300`（我脚本里的参考地板）、`450` 与 `380`（我脚本里的亮度门）、
`8662`（AEC 钉死的过期平衡点）。

**判据（外部复核给的，已写进报告）**：
> 一个常数合法，当且仅当 **(1) 它编码的量在会变化的那些东西之下物理不变**；
> **(2)** 存在**便宜的一次一用的验证**会在它失效时报警。

### C. 说超过证据（3 次）

- **"两路投票已实现"——错。** `qc_belt.py` 的 `verdict_decision()` 只读 `MB_DIFF_VERDICT`
  （**camera 0 的 diff arm**）。cam1 与 AND 的判定**发布但不上决策**。
  正确说法是三层：① 两路采集与各自比对（已实现）② 跨视角对齐（能形成但交集为零）③ 两路投票（**未实现**）。
- **"可检测性下限"——过强。** 十次尝试否掉的是那十条路，不等于任何方法都不行。
  正确说法：**在本批样本与当前配置下尚不能可靠检出**。
- **`and_ok=1` 不等于 AND 有效**：`and_cells=0` 说明它还没有内容可判。

### D. 工具/语法（3 次）

Tcl 里的 `$(...)` 不是命令替换（要用 `[...]`）；PowerShell 传 `"--order 1"` 会当成一个参数
（要传参数数组）；**在 UTF-8 无 BOM 的 .ps1 里写中文，PowerShell 5.1 按 GBK 读会乱码**
（脚本只用 ASCII）。
