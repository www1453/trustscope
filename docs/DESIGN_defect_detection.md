# ③ 真实缺陷检测 · 设计方案

> 目的：让系统从"评估成像质量"变成"检测 PCB 缺陷"。
> 现状：判定链只量亮度/方差/截顶/稳定性/对焦 ⇒ **一个缺陷都不识别** ✗
> 约束：纯软件、现有双相机、18 fps 预算、无基准板也能跑（但基准板可大幅增强）

---

## 一、要检什么（按商业价值排序）

| 缺陷 | 典型尺寸 | 视觉特征 | 难度 |
|---|---|---|---|
| **划痕 scratch** | 0.3–3 mm 长、0.05–0.2 mm 宽 | 亮线（暗场）/ 暗线（亮场） | 中 |
| **缺件 missing** | 元件级（1–5 mm） | 该亮/该有纹理处变平 | 中（需基准） |
| **偏移 offset** | 0.2–2 mm | 元件位置偏离 | 中（需基准） |
| **极性错 polarity** | 元件级 | 颜色/丝印方向不符 | 高（需规则） |
| **锡桥 bridge** | 0.1–1 mm | 亮连桥 | 中 |
| **立碑 tombstone** | 元件级 | 一侧翘起、阴影 | 高 |
| **异物 foreign object** | 0.1–2 mm | 不规则亮点/暗点 | 低（误报多） |

**最小可检尺寸决定分辨率**：0.5 mm 缺陷至少需要 **5 px** ⇒ **10 px/mm** ⇒ 视野 128 mm
**⇒ 当前约 5 px/mm** ⇒ **⇒ 只能检 1 mm 以上** ✓（先按 1 mm 交付，靠近或换镜头再提）

## 二、处理流水线（每帧）

```
全分辨率 1280×720（不是现在算法用的 640×360）
   │
   ├─① 照明归一化 illumination flattening
   │     背景 B = 大核均值/中值（如 31×31，用积分图 O(1) 求）
   │     输出 F = I / (B + ε)      ← 消掉灯的不均匀与缓慢渐变
   │
   ├─② 顶帽 top-hat（亮缺陷：划痕、锡桥、异物）
   │     T = F − min(F, 腐蚀(F))    用 3×3 方块，可分离实现
   │
   ├─③ 黑帽 black-hat（暗缺陷：缺件、裂纹、污点）
   │     K = max(F, 膨胀(F)) − F
   │
   ├─④ 自适应阈值 + 形态学
   │     阈值 = μ + k·σ（在 64×64 分块内各自算，避免全局阈值失效）
   │     去噪：开运算 1 次；连通域面积 3–500 px 保留
   │
   ├─⑤ 特征筛选（每个连通域）
   │     面积、长宽比（划痕 > 4:1）、方向一致性、灰度对比、位置（是否在 PCB 内）
   │
   └─⑥ ROI 掩码
        PCB 区域（亮/绿掩码 + 最大连通域）⇒ 只在此区域内判定
        手、背景、灯的反光全部排除 ← **这一条直接消掉当前的"光晕误判"**
```

**成本估算**（Zynq PS，单核 667 MHz，无 NEON 优化）：
- 积分图 921k px：约 8–12 ms
- 顶帽/黑帽 3×3 可分离：约 10–15 ms
- 分块阈值 + 连通域（降采样到 320×180 做种子，再回到全分辨率精修）：约 15–20 ms
**⇒ 合计 35–45 ms** ⇒ **与现有渲染 41 ms 相加约 80 ms ⇒ 12 fps** ✗

**⇒ 所以必须做的取舍**（三选一）：
| 方案 | 做法 | 帧率 |
|---|---|---|
| **A** | **检测每 2 帧做一次**（渲染每帧） | 18 fps 渲染 + 9 Hz 检测 ✓ |
| **B** | **检测在 640×360 上做**，缺陷位置再回全分辨率精修 | 18 fps ✓（但漏 0.5 mm 级） |
| **C** | **双核**：CPU0 渲染、CPU1 检测（需启动 CPU1） | 最快，但改动大 ✗ |

**推荐 A** ✓：不降分辨率、帧率只掉检测频率，最平衡。

## 三、有基准板 vs 无基准板

| | 无基准（reference-free） | 有基准（golden board） |
|---|---|---|
| 能检 | 划痕、异物、污点、大面积缺件 | **缺件、偏移、极性、锡桥** ✓ |
| 误报 | 高（纹理本身有起伏） | 低（差分后只剩差异） ✓ |
| 需要 | 无 | **一块良品板 + 对齐** |
| 实现 | 顶帽/黑帽 + 阈值 | **模板对齐 + 差分 + 阈值** |

**⇒ 交付先做 reference-free** ✓（不依赖你提供良品板 ✓），**基准版作为增强** ✓
**⇒ 如果你能给一块**良品板**（同型号 ✓），偏移/缺件/极性三项立刻可做 ✓ —— 这是**性价比最高的一件事** ✓

---

## 四、标定（必须做，否则"缺陷大小"没有物理意义）

1. **像素当量**：放一把钢尺或已知间距的标定板 ⇒ 量 100 mm 对应多少 px ⇒ **mm/px**
2. **畸变**：镜头畸变会让边缘尺寸偏大 ⇒ 用棋盘格标定一次 ⇒ 存 K、dist 系数
3. **两相机配准**：同一块板在两路里的对应关系（仿射即可）⇒ 可做**双路交叉验证** ✓（一路看到、另一路也看到 ⇒ 提高置信度 ✓）

**⇒ 交付文档里必须写清 mm/px** ✓（否则"检测到 0.8 mm 划痕"无法验证 ✓）

---

## 五、判定与输出

```
每个缺陷: {类型, 位置(x,y) mm, 尺寸 mm, 置信度}
整板判定: 不合格 if 任一缺陷超过阈值表
阈值表（建议初值，按客户标准改）:
   划痕 长度 > 3 mm 或 宽 > 0.2 mm
   缺件 任一
   偏移 > 0.3 mm
   异物 面积 > 0.5 mm²
```

**输出给上位机**：现有 Web 面板加一列"缺陷列表" + 图上画框 ✓（渲染层已有画框代码 ✓ 可复用 ✓）

## 六、分阶段落地（每阶段都能演示、都能回退）

| 阶段 | 内容 | 判据 | 工作量 |
|---|---|---|---|
| **①** | **ROI 掩码 + 排除高光** | `CLIP` 判定不再被灯反光主导 ✓ | 1 次构建 |
| **②** | **照明归一化 + 顶帽** | 人眼能看到划痕被高亮 ✓ | 1–2 次构建 |
| **③** | **分块阈值 + 连通域 + 特征** | 打印缺陷列表（坐标+尺寸）✓ | 2 次构建 |
| **④** | **全分辨率 + 每 2 帧检测** | 检 0.5 mm 级 ✓ | 1 次构建 |
| **⑤** | **基准板差分**（可选） | 缺件/偏移/极性 ✓ | 2 次构建 |

**每个阶段都要有**已知缺陷的样件**做验收** ✓ —— 否则无法证明"能检" ✗
**⇒ 这需要你准备 2–3 块**带已知缺陷的板**（可人为制造：划一刀、拆一个电容）✓

## 七、风险与依赖

| 风险 | 影响 | 对策 |
|---|---|---|
| **光照不均** | 阈值失效、误报高 | 照明归一化 ① 可抵消大部分 ✓ |
| **镜面反光** | 局部全白，缺陷被掩盖 | **双曝光融合**（已实现 ✓）+ ROI 排除 ✓ |
| **景深不足** | 板面高度差处模糊 | 缩小光圈/移远 ⇒ 但丢分辨率 ✗ ⇒ 需权衡 |
| **无已知缺陷样件** | 无法验收 | **必须准备** ✓ |
| **帧率** | 检测挤占渲染 | 方案 A（每 2 帧）✓ |

---

## 八、结论（一句话）

**③ 的骨架是「照明归一化 → 顶帽/黑帽 → 分块自适应阈值 → 连通域特征 → ROI 判定」** ✓
**交付先做 reference-free（不依赖良品板）** ✓，**有良品板后可加差分提升到缺件/偏移/极性** ✓
**最大依赖不是算法，是**已知缺陷样件**与**像素当量标定** ✓** —— 这两件需要你准备 ✓。
