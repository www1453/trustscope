# 提示词工作流 · 让模型写出"撤回记录"，而不是悄悄改口

> **任务形状**：你（或模型自己）在报告/总结里写过一句话，现在被测量推翻了。
> 你要的不是"再解释一下"，而是**一段可以放进报告的撤回记录**。
>
> **为什么这件事必须外包给提示词**：模型（和人都一样）面对自己被推翻的结论，
> 默认行为是**软化措辞**——"更准确地说"、"前面说的其实"、"补充一下"。
> 这些写法让读者以为你一直是对的。而评审（和未来的你）需要的恰好相反：
> 原句、新证据、影响面、已排除项。
>
> 本项目的真实案例：一个"帧平均没有收益"的结论被写成"已证实"，两天后
> 同一台工位上的另一次测量把统计量和场景都推翻，见 `../pitfalls/measurement-traps.md` M54。

---

## 提示词原文

```
我要撤回一条已经写进报告/文档的结论。请帮我写撤回记录，不要帮我解释。

原来的句子（逐字引用，不要改）：
  <原句>

推翻它的新证据（数字 + 文件/命令 + 日期）：
  <证据>

还有哪些后续判断/实现/报告段落建立在原句上：
  <影响面，如果没有就写"无">

请按这个格式输出，四段都要，不许省略：

  结论作废：<原句>
  原因：<新证据，带数值和命令>
  影响：<哪些后续判断建立在它上面，以及现在的正确说法>
  已排除：<被这次证据排除掉的假设，每条一句话>

三条硬要求：
1. 不要写"更准确地说""补充一下""前面说的其实"这类软化措辞；
2. 不要新增我没有提供的证据或数字；
3. "原因"一段必须能让读者不看上下文也判断出这是不是一次真撤回。
```

## 期望的产出（形状）

```markdown
**结论作废**：帧平均（N=8）对判据没有可分辨的收益。

**原因**：2026-10-26 的一变量 A/B（只写 MB_AVG_N，场景与参考不动）读出
N=1 sigma16 38.1/37.5、N=8 34.6/41.1/42.4，两臂交叠。但该 A/B 量的是
MB_DIFF_SIGMA，而判据读的是 MB_DIFF_CELLS >= 8 的计数；且那一帧参考偏了 40 px，
sigma 已被空间插值残差支配（N=1 时仅 2.4 grey，比 10-24 的 7.2 grey 安静三倍）。
在噪声地板上做的 A/B 测不出平均对噪声的作用。

**影响**：报告第 14.6 节原把"关掉平均"写成省时间的选项；现改为"未能复现收益，
不可据此关闭"。stage-2 的 2/43 → 0/47 保留，因为那是唯一量在判据输入上的证据。

**已排除**：H1 平均对判据无用（该 A/B 看不见判据输入）；H2 平均只是慢（省 28–44 ms
是真的，但那不是"无效"）。
```

## 失败案例（真实发生的三种）

1. **模型把撤回写成了辩护。** 它保留原句，加了一句"但在我们的场景下仍成立"，
   撤回变成了重申。**判据**：输出里还有没有那句原句？如果有，它没撤回。
2. **模型补了一个你没给的数字。** 它写"仪器噪声约 2 grey"—— 你的证据里没有这个数。
   **判据**：逐个数字核对，凡不在输入里的，删掉或标成"未提供"。
3. **模型把"影响面"写成"无影响"。** 而实际上报告里有两段建立在那句话上。
   **判据**：自己 grep 一遍原句的关键词，看它还出现在哪些文件里。

---

## 怎么判断它没照做

| 症状 | 说明 |
|---|---|
| 出现"更准确地说/补充一下/前面说的其实" | 它在软化，不是在撤回 |
| 输出比输入长很多，且多出的部分是新证据 | 它在编 |
| "影响"一段全是空话（"相关章节需要更新"） | 它不知道影响面，你要自己列 |
| 没有"已排除"一段 | 这次撤回不会阻止同一个假设下次复活 |

---

## 适用 / 失效条件

- **适用**：任何"已经说出口、被新证据推翻"的结论；也适用于**别人的**结论
  （把"原来的句子"换成对方原话即可）。
- **失效**：如果原句本身没有被推翻、只是**表述不够精确**，那不需要撤回记录，
  需要的是把证据等级标出来（E1 写成"服务层已就绪、目标层未验证"）。
  **两种场合混用，会让真撤回变得廉价。**
- **失效**：没有任何新证据时不要用这个提示词。没有证据的"撤回"是反复无常，
  和被推翻一样糟。
