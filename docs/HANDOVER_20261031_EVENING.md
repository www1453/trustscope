### 0.5d 关于 AI 视觉（深度学习）：为什么它也不解决这个

1. **没有标注。** 项目里没有缺陷像素级标注（报告"未测项"已写明）。训练一个定位划痕的网络需要划痕像素的 ground truth；若用格级 `darea` 当标签，模型学到的就是现有的格均值统计量。
2. **它看到的是同样的像素。** 三个投影的信噪比是 0.15 / 0.5 / 1.1。CNN 唯一可能优于匹配滤波的地方是利用**上下文区别**（沟槽有阴影和镜面高光，印刷走线是平的）——但那需要**带标注的样本量**，12 块划伤板远远不够。
3. **本仓库自己的 CNN 实验已经失败过一次，且是静默放行**：`dl/RESULTS_W1W2.md` 记 defocus 类**漏检 0%**（200/200 误放行）、`dl/STATUS.md` 记"危险放行 393/1000"。训练分布与现场不一致时，它的失败方式是**悄悄放过**——本项目最不能接受的失败方式。
4. **时间**：距 11/4 只剩 3 天，训练 + 验证 + 对照来不及。

**结论**：AI 视觉不是这条路的替代品，而是"需要另一些前提（标注、样本、验证周期）"的另一条路。在本次交付的时间与数据条件下不成立；报告里应写明这一条，而不是留一句"用了 AI"。

## 10. 2026-11-01 上午：传送带确认可用（E2）

**问题**：加上传送带能不能行？**答案：能——但节拍要写清。**

| 量 | 实测 |
|---|---|
| 皮带单次行程（1.0 s，100% duty） | **5 / 14 / 18.5 / 32.5 格**（2–13 mm），**打滑，不可重复** |
| 配准搜索范围 | ±49 格（±19.7 mm）→ **行程始终在范围内** |
| 停下后 `MB_REG_STATE` / `MB_DIFF_OK` | **1 / 1**（配准重新锁定，实测一次） |
| 停下 → 可判决 | **约 8 s**（年轻窗口：3 次真实比较，每 16 帧一次） |

**所以节拍 ≈ 10 s/件**（1 s 皮带 + 8 s 等待 + 判决），**这个数是报告里该写的，不是估算。**

**过程中排除的两个假故障**（都不在皮带）：
1. **曝光被钉在 8662** → `clip 12‰` > 闸门 10‰ → `MB_DIFF_OK = 3`，比较一律拒绝。解钉后曝光 4331、`clip 4‰`、`aec_state 1`。
2. **工具等待只有 2.5 s**，正好落在年轻窗口里 → 误报"未锁定"。改为 10 s。

工具：`dl\belt_reg_20261101.py --port COM8 --runs N --seconds S --duty D [--replace]`。
