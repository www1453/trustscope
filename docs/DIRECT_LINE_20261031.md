# 单板无参考线响应：第三条路线也被否（2026-10-31）

## 为什么要有这个实验

外部 brief 的第二问是：**"也许信息还在像素里，只是被参考差分淹没了"**。
前两条路线都带着这个嫌疑：

1. **格统计**（固件在用的）：8×8 格均值把 1–3 px 划伤从 58 灰稀释到 7–22 灰，
   良品自身纹理就到 13–29 灰 → 判死。
2. **像素残差 + 良品包络**（`pixel3`）：in-sample AUC **0.919**，
   但留一法（LOO）掉到 **0.669** → 那 0.919 是拿划伤板自己的位置调出来的，是过拟合。

两条都共用"减参考"这一步。**只要减了参考，配准残差和参考自身纹理就永远可以当
替罪羊。** 所以第三条路线设计为**完全不减参考**。

## 预注册（跑之前写死，跑完不许改）

- 输入：2026-10-29 那批原始帧（`dl/sweep_frames/20261029_181623_sweep/<label>/frame.bin`，
  1280×720 BGR，取 G 通道）。
- 参考只用于**定位 ROI**，不参与差分：`g0` 的平坦区门
  （`|grad(ref)|<30` 且 `55<=ref_G<=165`，腐蚀 5 px），ECC 仿射把实板配到参考坐标系。
- 统计量全部算在**实板自己的高通**上：`hp = live - blur(live, 31x31)`，
  再加 `sigma=1` 的 Hessian：`S_direct = max(lam_big)`（脊线选择性），
  `A_direct = max|hp|`（纯幅度对照）。
- 活体强度门：`50 <= blur(live,5) <= 170`，与平坦区门取交，排除焊盘/丝印/传送带。
- **判死线（跑之前写死）**：`AUC(S_direct) < 0.70`，**或** 在良品总体最大值
  `tau0` 上找不到任何划伤线条游程 → 该路线在这批数据上死。
- 阈值只从**良品**分布取（`tau0 = max S_direct over good`），12 块划伤板一次都没进来。

## 结果

```
tau0 (良品 S_direct 最大值)      = 812.9
AUC S_direct                     = 0.415
AUC A_direct                     = 0.517
划伤板在 tau0 上命中的线条游程   = 0 / 12
d30 已知划痕窗口：有效像素 649，max|hp| = 62.4 灰，max S = 173.6
```

`S_direct` 的全部 40 块良品与 12 块划伤板排在一起的分布是**完全重叠**的：
最高的几块是 d21 748 / d17 746 / **g29 744** / g14 739 / g21 735 ——
良品和划伤板混在同一段里，d30 的 652.7 落在正中。

## 怎么读这三个数（不要读多，也不要读少）

**能说的**：

- 三条互相独立的路线、三条都预注册、三条都判死：格统计（AUC 0.37–0.62，
  95% 区间盖住 0.5）、像素残差包络（LOO 0.669）、单板无参考线响应（**0.415**）。
- 划痕**确实在原始像素里**：d30 已知窗口的 `max|hp| = 62.4` 灰，与最初测到的
  "细划伤像素对比度约 58 灰" 一致。光子信号存在。
- 但**不存在任何能把它们分开的门**：同一块板上，已知划痕位置的线响应是 **173.6**，
  良品总体自己能到 **812.9**——差 4.7 倍，方向还反了。
  这不是"阈值没调好"，是**排序本身就不对**。

**不能说的**：

- 不能说"图像里没有划痕信息"。62.4 灰的高通幅度摆在那里，
  d30 的裁剪图肉眼也看得见。
- 不能把 812.9 解释成"良品板自身的纹理"。它更可能是**配准残差把焊盘边缘漏进了
  平坦区门**（门是从参考 `g0` 推的，配准残差 1–2 px 就足以让亮焊盘边界落进来）。
  这恰恰是本实验最硬的一句结论：**在这套光学 + 单参考 + 这套配准下，
  配准残差造成的假脊线比真实划痕强 4.7 倍。**

## 对交付的含义

- **划伤仍列 out-of-scope**，报告里的表述维持：该光学配置下原理性不可检。
- 升级路径维持唯一一条：**暗场斜射照明**（让划痕散射进镜头、把 58 灰对比度
  抬到百灰量级）。当前工位无可调灯位，未做。
- 可承诺的检出率维持不变：污染/异物 **18/21（85.7%）**，良品误报 1/41；
  划伤 1/12（CI 1.5–35%）不承诺；缺角 n=2 无信息。
- **固件 AND 移植不再等待这条路线**（它本来也不依赖），但也没有新的理由去动它。
