**可辩护区间**：缺角的判决阈值 **10 点** 位于 **(6.19, 10.57)** 之间（下界 = 非缺角板最大读数，上界 = 最小缺角读数）。

> （理由：同板重放 0.37 px 位移即产生 14.74 灰残差，而划痕格级信号仅 5–8 灰。）

## ④ 工程证据（数字照抄）

| 项 | 数 |
|---|---|
| **出货 bitstream 资源** | LUT **36,513 (68.63%)**、FF **58,900 (55.36%)**、**BRAM 138.5/140 (98.93%)**、**DSP 219/220 (99.55%)** |
| **时序** | **WNS +0.908 ns、TNS 0，140,009 条路径 0 违例**；FCLK_CLK0 50 MHz |
| **关键路径** | **在 CNN 内部**（`gmem2` RAMB36 → `conv3x3_32_32_32`，18.73 ns，88.7% 布线延迟） |
| **HLS 量化 CNN** | **位精确 8/8 KAT、31 ms/次、147,672 B 权重包**；**当前以自检形式运行，未接入判决路径** |
| **三道拒答门** | 噪声地板（同板重放 darea **1,0,4,3,2**）、光照一致性（差 >10% 拒判）、AEC 收敛（400 ms 内差 ≤4‰） |
| **可复算** | 每个判定可离线从存储的证据重算 |

**"为什么用 FPGA"的一句话**（PL 承重件）：
> 双路 AN5642 DVP 并口采集（**每路 24–28.5 MB/s**）在 PS 上按位捕获不可行；量化 CNN 是本设计的关键路径；**器件已用到 DSP 99.55%、BRAM 98.93%，时序仍满足**。

**"判定为什么在 PS"的一句话**：
> 每次比较的数据已从 **2.76 MB 降到 28.8 KB（约 96 倍降维）**；判决统计量迭代并否证了 **14 种候选**，搬进 PL 每否一次就要重做一遍硬件。**能上 PL，但在本阶段选择不上。**

## ⑤ 边界与下一步（不要删这一栏）

| 边界 | 处理 |
|---|---|
| 细划痕（2–3 px） | **不可检**，12 条统计量 + 参考维度 + 采样相位 + 亚像素配准四条独立否证；**归人工复检** |
| 缺角判据 | **离线验证 7/7，未上板**（固件判定区来自逐帧分割，缺角 0/31 格进区） |
| 光学放大 | **数字放大（1:1 裁剪）三次失败**（1:1 模式不出流）；**光学 2× 几何可行**（实测板宽 26.9 mm，2× 视野 32 mm） |
| 参考 | **只在同一固件会话内有效**（曝光 8662→2105 时帧均值只动 509→501‰） |
