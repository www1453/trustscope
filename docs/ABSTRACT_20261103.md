## 摘要（逐字，本次未改动）

本作品在 ALINX AX7020（Zynq-7020）上实现一台停带式来料检验工位：板由人工放上皮带进入视野，停带后以一块良品板的一次采集为参考，对活体帧逐格比对——160×90 格、8×8 px 一格、物方 0.4 mm/格；格均值差超过 30 灰且最大 8 连通组 ≥ 8 格判 NG。全部判定在板端裸机 PS 上完成，判定不依赖上位机；实测节拍 30–40 s/件——环路每 621 ms 才发布一次，一次可判判决要等若干次比较落定。

系统的中心是三值判决：0 合格 / 1 不合格 / 2 无法判定（CANNOT JUDGE）。固件规则是拒判一律判 2、绝不计为合格，因此每道门都往"判不了"的方向失效。三道可执行拒判门各带一个数：同板重放 5 次 darea = 1,0,4,3,2（实验室口径 ≤5，限值 8）→ 2×地板 ≥ 限值时该批不投票，现场良品地板实测 7、限值 8 因此贴近地板；亮度差 > 参考亮度的 10% 拒判（实测 1.6 倍差产生 62 格假残差）；落帧前亮度两次采样差 ≤ 4‰（实测 345‰ 的瞬时遮挡被拦下）。

能力按边界陈述：现场整批（2026-11-01 晚间、同一设备与固件、一块参考板、全作业单）三类能力内缺陷检出 40/55 = 72.7%（缺角一项走四角覆盖通道，在宿主侧对同一会话的帧复算，判据未进固件）；只取主运行 batch 1-5 的单会话锚点为 36/48 = 75.0%。良品误报两个口径分开标注：单次现场 6/40 = 15.0%（生产口径）、复测裁定 3/34 = 8.8%。细划痕 0/16 是已知能力边界——该类在格均值通道上无可分离信号，工序上划给人工复检工位，本工位的 OK 不作为该类的合格证明。

PL 承担采集、帧存与一个 HLS 量化 CNN 自检通道：两路 1280×720 实测 8.7–10.3 fps（2.76 MB/帧），CNN 8/8 逐位通过、29–31 ms/次，但不在判决路径上。出货比特流 DSP 219/220（99.55%）、BRAM 138.5/140（98.93%）、WNS +0.908 ns 仍满足时序；出货镜像连续运行 soak 10.20 h 无 NG，拒判全部落在启动瞬态。每个未达成的目标都走同一套否证程序（预注册 → 测量 → 归因或撤回），统计量、参考、采样、几何与时间四个方向，加上第五个学习方向的否证，收敛到同一结论：细划痕的格级信号低于结构性噪声地板，该边界由采样密度与照明几何决定。
