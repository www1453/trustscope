门限不到 2·N_g 就拒答。这条不给检出率，但能消灭"对缺陷板输出 OK"这个最贵的错误。

## 5. 唯一的软件改动（给交付物用，一天可做）

**判别力证书 + 三态裁决**（改 `ps_ui/main.c` 的参考建立与 `diff_verdict()`，不碰 30/8 两个常数）：

1. 建参考后要求把参考板**再放 5 次**（复用 `place_area` 流程），记每次 `MB_DIFF_DAREA`，取 **N_g = max(5 次)**。
2. 规则：**门限 ≤ 2·N_g → 该参考标记 NO_DISCRIMINATION**；此后内部通道一律输出 **CANNOT-JUDGE（理由=NO_DISCRIMINATION）**，
   并同屏显示 `N_g / 门限 / 判定格数`；只有 `N_g ≤ 3` 才允许输出 OK。
   外形/大连通组通道（`MB_OUT_*`）不受影响——10-29 的 other-def 证明它那条路还能用（16/26，0/41 误报）。
3. **验收判据（三条全过才算通过，回放即可，不用上板）**：
   - (a) 今天 21:52 的 5 次重放 N_g=4 → `8 ≤ 2·4` → 必须输出 CANNOT-JUDGE：**必须 5/5**；
   - (b) 10-29 的 16 块 other-def（组 16..43）→ 必须仍判 NG：**≥15/16**；
   - (c) 10-29 的 12 块划伤 → **0/12 允许输出 OK**（输出 CANNOT-JUDGE 或 NG）。
   任一条不过 = 此改动无效，回滚。
这条改动**不提高检出率**（这是 §0 的结论），但它把今天这种"对划伤板输出 OK"的假阴性换成一条带测量数字的拒答。
