# 环境变化的鲁棒性：实测"变一下环境就检测不了"到底有多真（2026-10-13）

脚本：`app/stability.py`（工具）、`app/selftest_stability.py`（工具自检）、`app/env_stress.py`（实验）
数据：`ps_ui/box_beforeA_*.bin`（9 帧，建参考图）、`box_beforeB_*.bin`（5 帧，测试）
—— 都是**真实采集**的帧，同一件、同一场景、没动过。

---

## 起因

用户质问："**可是这样变一下环境就无法检测肯定是不实际的啊**"。

这个质疑是对的。上一轮我的实验因为**台灯被动过**而作废（σ 从 2.13 炸到 23.66），
我当时把结论说成"仪器必须稳定"。但那等于承认系统很脆。
所以这一轮直接**量化**：环境变化到底打坏多少？加了工具之后好多少？

## 三件工具（`stability.py`）

| 工具 | 抗什么 | 原理 |
|---|---|---|
| **光照归一化** `normalize_illum` | 亮度漂移 | 把当前帧的稳健分位数（1%/99%）对齐到参考图上 |
| **相位相关配准** `phase_shift` | 平移 | 互功率谱取峰；超过 `max_shift` 则**拒绝**，不硬给答案 |
| **标定件自查** `GoldenMonitor` | 仪器漂移 | 用已知好件当标尺，它被判 NG 就说明仪器漂了 |

**工具本身先做了自检**（`selftest_stability.py`，用已知答案）：
- 平移：施加 (3,−5) 等 5 组 → 求回的平移能否**真的对齐回去**（功能性检验）
- 超限拒绝：施加 (+90,0) 且 max_shift=64 → 必须返回 (0,0)
- valid_mask 的无效像素计数：5 组全部与期望一致
- 归一化：已知 gain/offset 5 组 → 归一化后中位残差 **0.00**

> **自检救了一个正确的函数。** 第一版断言写成"返回值应当等于施加的平移"，结果全红；
> 但错的是断言 —— 施加 (p,q) 后要对齐回去需要的是 (−p,−q)，函数返回的正是它。
> 若当时去"修函数"，就会把一个正确的实现改成错的。

## 实验设计（受控对照，一次只变一个变量）

真实帧上做两组：
- **A 组（误报）**：好件**不加缺陷** → 任何 NG 都是误报
- **B 组（漏检）**：注入一条**已知位置、已知对比度（+25 灰阶）**的划痕 → 判 OK 就是漏检

每种扰动跑两遍引擎，**唯一变量是引擎模式**：
- **朴素**：`norm=None, register=False`（加工具之前的行为）
- **鲁棒**：`norm='robust', register=True`

## 结论

### 1. 用户的质疑成立：**改动前，"变一下环境就检测不了"是真的**

机制（这是本条最有价值的部分）：

```
thr = max(6σ, 8)      σ 从残差估出
灯暗 15%  ->  σ 2.13 -> 21.88   ->  thr 13 -> 131
注入划痕对比度 25   ->  **掉到阈值以下**  ->  5/5 全漏
```

> **不是"更难点"，是"完全测不到"。** 而且**它不会报错、不会报警** ——
> 系统照常输出"合格"，因为阈值自己长上去了。

**这一类失效是静默的，也是所有失效里最危险的一种。**
它同时说明了为什么"先量噪声地板"这条纪律必须做：**σ 是阈值的一部分，而 σ 会被全局变化污染。**

### 2. 两种环境变化的破坏方式**方向相反**

| 变化 | 朴素引擎的坏法 | 机制 |
|---|---|---|
| 亮度漂移 | **漏检** | σ 被抬高 → 阈值涨 → 小缺陷沉底 |
| 平移 | **误报** | 工件边缘错位产生差异 |

**所以"环境变化"不能用一句话概括** —— 它既可能让你放过坏件，也可能让你误杀好件。
两种都要测，只测一种会得出相反的结论。

### 3. 三件工具把两者都修好了

| | 朴素 | 鲁棒 |
|---|---|---|
| 9 种扰动下的 σ | 2.1 → **21.9** | **2.04 – 2.27**（始终贴着噪声地板） |
| 注入划痕的检出（9 种扰动） | **4/9 种下全漏** | **9/9 种下 5/5 全检出** |
| 误报 | 3/9 种下 5/5 误报 | **0** |

### 4. `σ` 本身就是一个极好的哨兵

正常 2.13；任何扰动下 4.8–21.9。**不需要额外硬件，这个数已经在算了。**

> → **"仪器漂了"可以自动发现，而不是靠实验失败或靠人眼。**

## 局限（跟结论一起报）

- 注入的划痕是**亮度变化**，不是法向变化。所以它测的是**亮度通道**。
  法向通道（光度立体）对亮度漂移是**原理性免疫**的（`g'=k·g -> n=g/|g|` 不变），
  这条不需要实验就已经成立，但**要用它得有 4 个灯**。
- 平移扰动是**纯平移**。真实相机移位还带着透视、阴影、镜面高光的变化，
  纯平移是简化模型。
- 归一化用稳健分位数，**它会把大面积的均匀缺陷一起抹掉**。这是"容忍漂移"的必然代价，
  不是 bug。要查大面积均匀缺陷，得靠色度或画面里的参考片。
- 配准是整像素平移，**不覆盖旋转/缩放/方向漂移**。方向漂移只能靠机械固定。

## 对"仪器必须稳定吗"的回答

**不是"必须像素级绝对稳定"，而是：**

| 要稳定的 | 要求 | 怎么达到 |
|---|---|---|
| **方向**（灯、相机） | 大致不变（几度内） | **拧紧螺丝**（一次性） |
| **亮度** | **不需要** | 归一化（已实现并验证）+ 法向通道（原理免疫） |
| **位置** | 不变，或配准 | 固定，或相位相关（已实现并验证） |

**"亮度"和"位置"这两条现在都不用靠机械保证了。**
