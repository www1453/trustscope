## 1 方法（实现的参数，全部出现在 `--json` 的 `params` 里）
- 板掩膜 `MASK_RULE=greenmax`：`G − max(R,B) > 5`（int16），3×3 闭运算、填洞、最大 **8** 连通域。
- 四边形：掩膜外轮廓点；`EDGE_MIDDLE=[0.2,0.8]` 的 bbox 范围内，每列（上下边）/每行（左右边）取**最外**板像素，每条边做带 `EDGE_TRIM_PX=3.0` 残差裁剪的鲁棒直线拟合，四线两两求交 → TL/TR/BR/BL。
- 精修：边界点按 `EDGE_BAND_PX=12.0`（点数 < `EDGE_MIN_POINTS=30` 时放宽到 `EDGE_BAND_WIDE_PX=20.0`）分配给最近的边、重拟合、重求交；**仅当每个顶点相对初始拟合移动 ≤ `EDGE_MAX_MOVE_PX=2.0 px` 才接受**，否则保留初始拟合（`edge_iters` 最多 3 轮）。这条约束是必需的：无约束的迭代在 10-31 good3 上把四边形挪了 9.7 px，TR 角凭空多出 4.6 点。
- 重采样 `CANVAS=ref`：4 点单应（DLT + Hartley 归一）把活体板四边形映到**参考板自己的四边形**（参考帧坐标），双线性；参考本身不做重采样（同象限→逐位相同，这是自检"精确 0"的来源）。
- 窗口 `WIN_PX=128`：128×128 px 正方形，中心在参考板四顶点。**窗口边长 = 参考板短边 256.5 px 的 0.50**（探索代码用的就是固定 128 px，记录在此）。
- 覆盖率 = 窗内板像素占比 ×100（**点**）；`delta = 活体 − 参考`，一角一个。判定：最负 delta ≤ −`threshold`（默认 10.0）→ `CORNER`，否则 `OK`。
- 工具接口：`python dl\corner_cov_20261101.py --ref <frame> --test f1[,f2...] [--json out.json] [--threshold 10.0] [--selftest]`；`--test` 可重复。`--json` 每帧存 `coverage_pts`（四角）、`delta_pts`（四角）、`max_abs_delta_pts`、`worst_corner`、`verdict`，外加两块的 `quad`／`quad_quality` 和全部 `params`。

## 7 固件要跑在目标上，缺的是什么（E1）
- **已经有了**：逐 8×8 块的 `G−max(R,B)` 分数（`ps_ui/main.c:6337-6348`，2×2 采样 + 截尾均值）；8 连通最大组 `cc_largest()` 与 flood fill 栈（`main.c:11907`，28,800 B，DAREA 规则已在用）。
- **缺的只有一件：板的轮廓。** `mask.bin` = `LIVE_MASK`（160×90 格 / 14,400 B / `main.c:4943`）是"分数 > 帧中值+边距 → 3×3 腐蚀 → cluster"之后的**存在性**掩膜，不是轮廓。实测 10-29 g0：698 格 = 板自身 1913 格的 **36.5%**、= 固件自报 part bbox（66×32 格）的 **33.0%**（文档"35%"介于两者之间，E1 一致），且四个 bbox 角落基本是空的。缺角处它恰好是空的——**用它拟合边，边会被缺角带弯**。
- **要新增的阶段**：(a) 一份**填充、不腐蚀、固定阈值**的轮廓掩膜（+14,400 B/视路，或让 LIVE_MASK 与它共存）；(b) 四边鲁棒拟合 + 4 点单应；(c) 参考侧存四顶点（8×int16）+ 四个参考覆盖率（4×float）+ 窗口边长（≈40 B）。
- **代价**：轮廓掩膜一趟 160×90（与现有掩膜同一量级）；**填洞是新代码**（一次 14,400 格扫描）；拟合 ≤600 个边界点 × 4 条线；每板覆盖 = 4 窗 ×16×16 格 = **1024 次格测试**（160×90 的 7.1%）。判定区（`LIVE_MASK AND 映射后 BASE_MASK`）与逐格统计**一行不用改**——这是"新增一级"而不是"改一个阈值"的原因。

## 8 这个统计量**不做**什么（E1）
- **只查四个角**：窗口在角上 128×128。**直边中段的缺陷（缺料、缺口、划伤）不在窗内 → 无信号**；四个窗合计只覆盖板面积约 **12%**（4×16384 px × 23% 命中率 = 15,073 px，板 122,447 px）。
- 不测"缺了多少面积"：10 点 ≈ 窗内 1,638 px ≈ 26 个 8×8 格。它问的是"角还在不在"。
- 板整体平移/旋转/缩放由单应吸收 → 不报；**弯板**会移动角（10-27 d1 +10.49、d2 −9.71），是本统计量最接近阈值的一类。
- 依赖板轮廓可拟合：掩膜残到 `area/bbox 0.69` 的 d12 就是这种情形（它恰好不是缺角板，所以不影响验收，但这是它的失效模式）。
