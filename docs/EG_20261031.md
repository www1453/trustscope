# 2026-10-31 — 格内极差统计量（EG）：台账先查、配对判据、结果是否定的

> 这一轮回答一个问题：**固件里早就有的"格内极差"统计量（`MB_EG_CELLS/MAXD`），
> 能不能把划痕类和良品类分开？**
> 答案：**不能**。三处独立证据同向：站台自己记录过的良品零值（95–121 灰）落在划伤类的
> 取值范围中间；离线原型上划伤类的中位数**低于**良品类；配对 bootstrap 的 ΔAUC 区间跨零。
> 这条杠杆从"未试"改成"已证否"。

## 0. 先查台账（改了说的第一条：别把已记录的当新东西）

`MB_EG_*` 在主机词表里是完整的（`dl/host_qc/qc_mailbox.py`：553 eg_on / 554 eg_thresh /
555 eg_thr_used / 556 eg_cells / 557 eg_maxd / 558 eg_at / 559–562 外框 / 572 margin / 573 roi）。
历史上**确实被记录过**：

- 六个 `accept_range_2026*.csv` 有 eg 列，但合计只有 **9 行**；
- 9 行**全部是良品**（g0/g1/g2 各 3 次摆位）；
- 80 块板的人口台账（`sweep_*`）里**没有** eg 列；50 个历史 `state.txt` 里也一个都没有。

所以准确的说法是：**良品侧的零存在，缺陷侧的分离度从未被测过。**

```
良品侧（站台自己量的，固件自己的管线）: eg_maxd 95 / 101 / 109 / 120 / 121  (差 = 95..121 灰)
                                       eg_cells 39..130
```

## 1. 固件到底算的是什么（改了说的第二条：别把"像素极差"当成可部署量）

`cell_mean8_ex()`（`ps_ui/main.c:4699`）：每格取 **4 个抽头**，抽头中心在格内
`(FINE_SAMP, FINE_SAMP) = (2,2)`、`(6,2)`、`(2,6)`、`(6,6)`，每个抽头是
`FINE_TAP × FINE_TAP = 3×3` 的均值；`range = hi − lo`（这 4 个**已平滑**抽头之间）。
`EG_THRESH_DEFAULT = DIFF_THRESH = 14 灰`；`MB_EG_MAXD` 是与阈值无关的那个数。

因此：

- **版本 A** = 4 个 3×3 抽头的极差 → **零构建可部署**，它的分离度才是决策依据；
- **版本 B** = 64 个原始像素的极差 → 只能回答"3×3 平滑是不是损失的原因"，
  **如果只有 B 赢，结论是"要改采样"，不是"可以改固件"**。

两个版本都算了。

## 2. 预注册判据（写在看数之前）

- 主判据：**同一批板上，ΔAUC = AUC(EG A) − AUC(8×8 均值残差) 的配对 bootstrap 95% 下界 > 0**
  （按板重采样；配对比较用掉了相关性，功效高于两个独立 AUC 相比）。
- 为什么不是"AUC ≥ 0.80"：n=12 正样本时，AUC 0.80 的 95% 区间约 **[0.64, 0.96]**，
  基线 0.44 的区间约 **[0.26, 0.62]**，两者几乎相接——一个点估计放不住。
- 附加前提：划伤类要**先超过**站台记录的良品零（95–121 灰），再谈 AUC。这一条不满足，
  后面的统计量再漂亮也是零噪声。

## 3. 数据（26 块的 10-29 原始帧，离线，零站台时间）

对齐：整数平移 + 中位数增益补偿；只统计板体掩膜腐蚀 2 格后的内部（不含板边）。
（原型没有固件的亚像素配准与逐格容差——见 §5 的边界。）

```
n 划伤 = 10   n 良品 = 9   （d25/d32/g12/g17/g28/g11 的掩膜腐蚀后内部不足 200 格，跳过）

量                  划伤中位数    良品中位数
8×8 均值残差 max        51.6          89.1
EG A（固件抽头）max    123.5         127.9
EG B（64 像素）max     178.4         188.0
EG A cells (>14)        71.5          86.0
```

逐块 `egA_maxd`：

```
划伤：128 104 121  60 136 132 141 126 118 114     中位 123.5
良品：127  46 128 132 124 119 138 130 138         中位 127.9
```

**良品的中位数比划伤还高。** 划伤里最高的 141 只比良品最高的 138 高 3 灰，
而站台自己量到的良品零是 95–121——**零就坐在划伤类取值范围的中间**。

## 4. 判据的结果

```
统计量                 AUC      ΔAUC 配对 CI（相对 8×8 均值）
8×8 均值残差           0.378     [+0.000, +0.000]   （基线自身）
EG A（固件抽头）       0.394     [-0.356, +0.394]   ← 跨零，且点估计 < 0.5
EG B（64 原始像素）    0.372     [-0.356, +0.333]   ← 同上
```

**判决：不通过。** 不满足 §2 的主判据，也不满足附加前提（划伤没有超过 95–121 的零）。
按预注册，**不为它改固件**。

## 5. 这个结论的边界（不许省略）

1. **原型的对齐比固件弱**（整数平移 vs 亚像素搜索 + 逐格容差），所以它的绝对分离度**不能**
   当作固件 EG 的最终判决。但**站台自己记录的良品零（95–121）与划伤类的取值区间重叠**
   这一点不依赖原型——它是站台的数。
2. 两个版本都输，且方向都是"良品更高"，说明差异被**摆位/参考**主导，不是被缺陷主导。
   这与今天的另一条测量一致：划伤板在判格上的 z 均值 0.168 vs 良品 0.158。
3. **不据此否定"改采样"这条路**：版本 B 也没赢，但那是在同一个弱对齐下的结果；
   若要做，应该在固件的配准之后再用原始像素，而不是在离线原型里。
