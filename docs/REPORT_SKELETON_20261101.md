# 报告骨架（2026-11-01 冻结）—— 每一节都带上可追溯的数

> 用法：按节填。**每个数都带分母和批次**（GLM 指出的最危险一条：两份文档检出率口径打架）。
> 交付物不含任何学校信息（海报除外）。

## 0. 一句话定位

一台 Zynq-7020 裸机 AOI 工位，用**三值判决**（NG / OK / **无法判定**）代替假答案：
大缺陷与缺角**可检**（有数、有分母、跨批次），细划痕在当前采样与光照下**不可检**（12 条路，每条有数）。

## 1. 系统与判据链

| 项 | 值 |
|---|---|
| 平台 | XC7Z020 裸机 PS，单相机 1280×720 BGR，0.05 mm/px（视野 64 mm） |
| 判决 | 160×90 格（8×8 px = 0.4 mm），格值 = 格内 4 个 3×3 采样盒均值（**36/64 像素**） |
| 阈值 | 格均值 \|活体−参考\| > 30 灰，最大 8 连通组 ≥ 8 → NG |
| 参考 | 一块良品板拍一次（`MB_CMD=9`），配准搜索 ±8°、0.05°、±19.7 mm |
| 当前固件 | **`TSC189F5713E`**（所有实验改动已回滚到出厂行为） |

**三条工程门（本项目的核心设计主张）**
1. **噪声地板门**：同板重放 5 次 `darea` = 1,0,4,3,2（地板 4，限值 8）→ `2×地板 ≥ 限值` 时**拒绝判决**。
2. **光照一致性门**：参考与活帧亮度差 > 10% 时拒判（实测 1.6× 差 → 假残差 62 格；1.15× 差仍可接受）。
3. **AEC 收敛门**：落帧前要求亮度连续两次（400 ms 间隔）差 ≤ 4‰（实测一次 345‰ 的瞬时遮挡被拦下）。

## 3. 缺角：唯一满足工业验证要求的判据

- **方法**：绿色掩膜（`G − max(R,B) > 5`，**不能用均值版**，否则缺角被填回去）→ 最大连通域 → 四边拟合 → 映射到**参考板的四边形**（不能映射到轴对齐矩形，底边压缩 ×0.907 会丢 22% 缺角像素）→ 四角窗口覆盖率。
- **自检**：参考帧对自己 = **+0.00（逐位相同）**；合成 60×50 px 缺角 → 该角 −16.70、其余 ≤0.02。
- **失效模式（必须写）**：
  1. **单应的 8 个自由度会吸收任何"能被全局射影解释"的缺失**（整板偏小、均匀缩放）→ 能力边界是"能检**无法被单应解释**的角缺失"。
  2. **边中缺口结构性失明**（四角窗只覆盖板面积 ~12%）；g1 底边本身就有设计半圆缺口。GLM 实测：全周向轮廓 XOR 可补（48/48 良品零误报）。
  3. **弯板会移动角**（10-27 d1 +10.49、d2 **−9.71**，距阈值仅 0.29 点）——**这是真实分离度 1.07 倍的来源，必须写**。
- **板上状态**：**离线验证，未上板**。固件 `LIVE_MASK` 是存在性掩膜（只覆盖板面积 36.5%，四角为空），需要新增"填满轮廓掩膜 + 填洞 + 四边拟合 + 单应 + 参考侧 40 B"一个阶段。**3 天内不做板上出货声明。**

## 4. 划痕：12 条路，逐条有数

格均值（0/12）· 4×4 子格最大（AUC 0.5）· 格内极差 EG（**良品 33/39 误报、AUC 0.301**）· 色度 R−B（方向反）· 平坦区像素阈值（良品 70 px vs 划痕 0–33）· 原图线状匹配滤波（20.1–24.5 vs 22.3–27.7）· 平移对齐差分滤波（19.3–33.7 vs 19.2–24.4）· **正确配准后的差分滤波（17.5–34.2 vs 16.9–20.2）**· 比值归一（8.82 vs 8.91）· 奇对称沟槽核（14.64 vs 12.78，反向）· 24 方向覆盖（+6% vs 良品 +3%）· **R1 投影+亮度场配准（33.2→30.0 灰，投影参数 p6=p7=0.0）**

**结论的精确措辞**（不要写成"原理上不可能"）：
> 同板重放 0.37 px 位移即产生 **14.74 灰**残差，0.62 px 为 22.62 灰；而同板重放本身在格级就有 **2 格**超阈。**表征层的误差与缺陷信号同量级，换统计量是在已被污染的量上换度量。**

**唯一确定升级路径**：暗场/掠射照明或 ≥2× 放大（硬件）；2× 裁剪三次失败（1:1 模式不出流）。

## 5. 传送带与节拍

行程 5–32.5 格（2–13 mm，打滑不可重复），**全在配准 ±49 格内**；停下后 `regstate=1`、`diffok=1`（实测）。
**节拍 ≈ 10 s/件** = 1 s 皮带 + **8 s**（年轻窗口：3 次真实比较）+ 判决。

## 6. 实时网页

`http://127.0.0.1:8801/`：缩略图 4.3–5.0 fps（位置/运动），整幅 4.2–5.1 s（细节，0.20–0.24 fps，可能撕裂）。
**JTAG 上限 ≈ 576 KB/s**——任何"宿主侧整幅实时处理"在此通路不可能，像素级统计量只能跑在存下来的帧上。
失败模式已验证：停核心 → CORE HALTED / FROZEN；杀 hw_server → STALE + 自动恢复。


## 6.5 能力边界的量化与机制归因（**放在"完成情况"之后、"总结"之前；标题里不出现"失败"**）

**本节可直接粘贴。** 本作品对每一个未达成的设计目标执行**同一套否证程序**：
冻结判据与停止条件（预注册）→ 测量 → 机制归因或撤回。

| 维度 | 被否证假设 | 否证证据 | 机制 | 证据文件 |
|---|---|---|---|---|
| **统计（12 条）** | 格均值 / 4×4 子格 / 格内极差 / 色度 / 平坦区 / 线匹配×3 / 比值归一 / 奇对称核 / 24 方向 / 投影配准 | AUC **0.36–0.52**；EG 良品误报 33/39 | **残差与信号同形**：artwork 错位本身就是一条细线 | `K_SWEEP`、`EG_STATISTIC`、`R1_REGISTRATION` |
| **参考** | min-over-K / m-of-K / 逐格 min / 逐格白化 / 离线选参考 | 全部 **≤ 单参考**（19/21 vs 17.1/21 等）；41 个候选全 0/40 误报 | **共模 + 取最小 = 与逻辑**，只买特异性 | `K_SWEEP`、`REFSEL`、`MULTIREF2` |
| **采样** | 36/64 → 64/64 | 相位抹平器，比值 **0.75–1.5×**；真实划痕 30 灰下 **2 格 → 0 格** | 期望不变，仅消相位方差，不足以跨幅度地板 | `CELL64` |
| **几何 + 时间** | 亚像素配准 / 时间维度 | 同板 0.37 px → **14.74 灰**；时间维度**解析关闭**（静态噪声与缺陷同静） | 信号 **5–8 灰 < 结构性地板** | `R1_REGISTRATION`、`SOFTWARE_ONLY_AUDIT` |

**收敛结论（三句）**：四个维度的否证收敛到同一量化结论——在 0.05 mm/px、非方向光、单参考条件下，细划痕的格级信号低于结构性噪声地板；该边界由**采样密度与照明几何**决定，不由阈值或统计量决定；因此设备对其输出 **CANNOT-JUDGE 而非漏检假象**，划痕类由检验策略中的**人工复检工位**承担。

**收尾句**：每条否证的判据、数据与脚本随提交包归档，可由第三方复算。

**（时间维度的解析证明，一行版）**：对判决构成约束的噪声（板间身份差 + 姿态失配）与缺陷一样在时间上**静态**；时间维度只能区分"静态信号 vs 时变噪声"，而时变噪声已被 8 帧均值消掉（实测：静止板 N=1 时 86 次比较 2 次超限、N=8 时 90/90 为零）。**故时间维度对本缺陷类不含判别信息，无需实验。**

## 6.6 器件用满这件事（**新发现，写进 1.4 / 2.2**）

**出货 bit：DSP 219/220（99.5%）、BRAM 138.5/140（99.0%）、LUT 68.6%、WNS +0.908 ns。**
三重意义：
1. **"器件整体性能发挥"的顶级证据**；
2. **决赛窗口 L1 的硬约束**——**BRAM 已无余量**，格统计进 PL 必须先做资源置换（砍帧缓冲 / 复用行缓冲）；
3. **边界真实性的旁证**——这台器件连"再加点硬件试试"的余量都没有。
