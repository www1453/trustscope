# 演示视频分镜脚本（2026-10-25 版）

> 目标：3–4 分钟，让评委在**不看代码**的情况下相信三件事 —
> **① 良品能判合格 ② 表面缺陷能判不合格 ③ 判不了的时候它说"判不了"，而不是乱给结论。**
> 全程不出现学校、姓名、学号、导师、班级等信息。
> 每一镜都写清"画面要让评委看到什么"，做不到的镜头宁可删掉，不要用话术糊过去。

---

## 拍之前的准备（10 分钟）

| 项 | 要求 |
|---|---|
| 板子 | 电源插好、LCD 亮、画面里能看到皮带和工件 |
| 工件 | **一块确认良品** + **一块表面有污染/发黑的不良品**，各放一处，别混 |
| 位置 | 工件放在**画面中下部、白色皮带上**（x 540..1104，y 370..660），长边与皮带边平行 |
| 手 | **取参考之后手不要进画面**（进画面 = 画面在动 = 系统拒绝判定，这是正确行为但要避免） |
| 拍摄 | 手机横屏，固定机位（三脚架或用东西垫住），**同一角度拍完全程** |
| 光线 | 拍摄期间**不要开关灯、不要拉窗帘** |
| 时间 | 每块板放好后**等 3–5 秒**再切镜头（系统要 8 帧平均 + 稳定期） |

**一句提醒**：视频里所有数字都来自屏幕，**不要后期配音念一个屏幕上没有的数**。评委最容易抓的就是这个。

## 镜 1｜开场：这是什么（0:00–0:20）

| | |
|---|---|
| **画面** | 全景：皮带 + 双相机 + 开发板 + LCD（一镜拍全） |
| **字幕** | TrustScope · Zynq-7020 双目可信成像质检 |
| **旁白** | "这是一套在传送带上做外观质检的系统。两颗相机同时看同一个工件，一块板子负责采集和判定，结果直接显示在这块屏上。" |
| **要证明** | 系统是完整的实物，不是 PPT |

---

## 镜 2｜良品 → PASS（0:20–0:55）

| | |
|---|---|
| **画面** | ① 把**良品**放到皮带上 → ② 镜头推近 LCD：**判定 PASS**、工件内差异格数、帧率 |
| **字幕** | 良品 · 判定 PASS |
| **旁白** | "放一块良品。系统先对齐，再逐格比对。这一块：工件内超阈值的差异是 0 格，判合格。旁边这个数字是实时帧率。" |
| **要证明** | **良品不会被误判**（这是误报率，比漏检更常被质疑） |

**拍摄要点**：**先取参考**（在良品上按 SET REF 或由我下发命令），再拍这一镜。参考必须是良品。

---

## 镜 3｜不良品 → NG（0:55–1:40）

| | |
|---|---|
| **画面** | ① 换上**表面污染的不良品** → ② LCD：**判定 NG**、差异区域被框出 → ③ 手拿板子对着镜头给一个近景：**污染在哪** |
| **字幕** | 表面污染 · 判定 NG |
| **旁白** | "换成一块表面被污染的不良品。同一张参考、同一个位置，系统判不合格，并且框出了差异所在的区域。" |
| **要证明** | **真缺陷不会被放过**（这是这套系统的存在意义） |

**拍摄要点**：**近景那一拍很重要**——评委要能看出"这块板确实脏了"，否则 NG 没有说服力。

---

## 镜 4｜它凭什么判（1:40–2:20）

| | |
|---|---|
| **画面** | 笔记本屏幕（或用手机拍 LCD 旁的读数）：**参考帧 vs 实时帧的对齐量、工件内差异格数、容差图里放宽了多少格** |
| **字幕** | 判定依据：工件内差异 · 逐格容差 · 对齐残差 |
| **旁白** | "判定不是整幅图比一次，而是三步：先把工件对齐；再逐格比差异；最后只看工件内部的格子，而且这些格子还带着从四块良品学来的容差——本来就会变的地方不参与判定。" |
| **要证明** | **不是"黑箱说 PASS/NG"**，有可解释的量 |

---

## 镜 5｜位置变了还能判（2:20–2:50）

| | |
|---|---|
| **画面** | 把良品**挪 2–3 厘米**（不要超出这个范围）→ 等 5 秒 → LCD 仍然 **PASS** |
| **字幕** | 重新摆放 · 仍然 PASS |
| **旁白** | "把工件挪一个位置，不用重新标定，配准会自己找回来。" |
| **要证明** | **不是"必须放在原位"**（这是配准的价值） |

**拍摄要点**：**只挪 2–3 厘米、转几度**。挪太远（5 厘米以上）系统会报"无法判定"——那是正确行为，但这一镜里不要演。

---

## 镜 6｜看不清就说看不清（2:50–3:20）

| | |
|---|---|
| **画面** | ① 把工件**拿开**（空皮带）→ LCD 显示 **无法判定** → ② 或者：用手挡一下镜头 → 同样"无法判定" |
| **字幕** | 看不清 · 无法判定（不是"合格"） |
| **旁白** | "把工件拿走，或者遮挡一下镜头。系统不会猜，它说无法判定——这是这套系统最重要的一条设计：看不清的时候绝不判合格。" |
| **要证明** | **失败方向是安全的**（这一条在很多项目里是缺的） |

---

## 镜 7｜边界（3:20–3:50）

| | |
|---|---|
| **画面** | 静态图表（不是实拍）：一张"能检出/检不出"的尺寸对照表 + 一句工作条件 |
| **字幕** | 可靠检出约 2 毫米级；低对比缺陷不保证；需固定光源与相机 |
| **旁白** | "它也有边界：小于约 2 毫米的缺陷、和底色接近的低对比缺陷，都不保证能检出；光源和相机必须固定。这些边界我们写在技术文档里，不回避。" |
| **要证明** | **团队知道边界在哪**（评委最看重这一点，比"我们什么都能做"强得多） |

---

## 镜 8｜收尾（3:50–4:00）

| | |
|---|---|
| **画面** | 全景 + 屏幕上的判定 |
| **旁白** | "一块板子完成采集、对齐、比对、判定和显示；看不清的时候说不清。" |

## 剪辑与配音

1. **字幕全程带**（很多评委静音看）；
2. **数字一律来自屏幕**，不要念屏幕上没有的数；
3. 全长控制在 **4 分钟内**，超过 4 分钟评委看不完；
4. 导出 **1080p、H.264、MP4**，文件名 `demo.mp4`；
5. **不要放背景音乐盖过旁白**。

## 拍完自检（逐条打勾）

- [ ] 良品 PASS 的镜头**清楚看到 PASS 和差异格数**
- [ ] 不良品 NG 的镜头**清楚看到 NG**，并且有**近景说明缺陷在哪**
- [ ] "无法判定"那一镜**真的拍到了**
- [ ] 全程**没有出现**学校、姓名、学号、导师、班级、桌面路径
- [ ] 画面里**没有**与项目无关的窗口、聊天软件、文件管理器
- [ ] 时长 ≤ 4 分钟
