## 五、必须记住的六条（这十天换来的）

1. **先量零对照，再跑人群** —— 一个统计量如果连"自己和自己比"都不接近零，它没有资格进人群测试。
2. **结论不得强于证据** —— 没测的说没测，测反了就撤回，并写清是哪一步错了。
3. **一个数必须能追到一个文件** —— 被 git 忽略的文件不算证据。
4. **仪表必须先被"能失败"地验证过** —— 今天的 M57：AXI 的 RRESP 不看也能数出 46,800 拍；七值信标被当循环计数器。
5. **LUT 百分比不是面积** —— 一个 slice 装 4 个 LUT，"31% 的 LUT 空闲"与"4.6% 的 slice 空闲"同时成立。
6. **回退路径要能在"上游全坏"时工作** —— PL 前端每笔事务被拒一整晚，工位照常出结果。
