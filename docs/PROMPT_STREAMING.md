# 新会话启动提示词（流式 RTL / 流式 HLS 内核重写）

> 用法：**整段复制下面代码块里的内容**，粘贴到新会话的第一条消息。不要改里面的路径。
> 提示词已经做了三件事：指定先读哪些文件、把纪律写死、给出停止判据。
> 如果只想做别的（比如写报告、做经典路径的 PL），把开头「本次任务」那一行换掉，其余照抄。

## 为什么这样写（给自己看的，粘贴时不用带）

| 提示词里的内容 | 防的是哪个具体事故 |
|---|---|
| 强制先读 4 份文件 | 上次新会话不知道结论已被推翻，从头重试 |
| 列出三条**已被推翻**的假设 | 重复走权重访存/加法链/分辨率三条死路 |
| 每次删 `hls_proj` | T14：增量缓存给出"逐位相同"的假结果 |
| 综合前台跑 | 后台 HLS 被沙箱回收，trace 停在 `csynth_design` |
| 纯 ASCII | GBK 误读报无关语法错 |
| 主机 bit-exact 优先 | 用分钟级反馈验证秒级就能验证的东西 |
| 明确停止判据 | 上一次的失败模式：无止境地调一个可能不该用 HLS 做的东西 |
| "逐位相同是异常信号" | 同上，这条让缓存问题 5 秒内暴露 |
