## 建议稿

本作品基于 ALINX AX7020 开发板，以 Zynq-7020 的 PS+PL 协同架构为核心，面向**平面工件**（PCB 裸板等）构建可信成像质检系统，输出**合格 / 不合格 / 无法判定**三态结果。

**核心主张**：工业质检最常见的失效不是"判错"，而是"**看不清却照判**"。本系统把**成像可信度**作为判定的前置条件——当关键区域饱和、场景发生全局变化、或仪器发生漂移时，系统主动输出"无法判定"并推送人工，而不是给出一个没有依据的结论。

**已实现并有实测支撑**

- **采集与显示链路**：OV5640 1280×720 采集，VDMA + DDR3 帧缓存，800×480 本地显示；PS 侧相位计时逐段可测（整环 60.45 ms，其中相机渲染占 90.0%，实测帧率 16.54 fps，反推时钟 332.5 MHz）。
- **判定引擎**：中位数参考图 → 自适应阈值（max(6σ, 8)）→ 形态学开运算 → 连通域 → 面积×对比度打分 → 三态输出。
- **参考图锁定**：修掉了"同一系统性缺陷连续出现时被学成背景"的缺陷。实测：未锁定时同一件第 6 次判定翻面；锁定后连看 12 次分数完全一致。
- **环境鲁棒性**：加入光照归一化与相位相关配准。9 种受控扰动下，改动前有 4 种导致全部漏检、3 种导致全部误报；改动后 9/9 全部检出、0 误报，σ 始终稳定在 2.04–2.27（正常值 2.13）。
- **标定件自查**：以已知好件为标尺判断仪器漂移，阳性对照 0/5 报警、阴性对照 5/5 报警，分离度 5.5 倍。
- **遮光与照明**：实测纸箱把环境光压到满量程的 2.7%（17.1 倍抑制），逐像素噪声地板 2.0 灰阶。
- **多角度打光的量化结论**：单光源对划痕的漏检率 14%（且与划痕朝向相关），四路各自判定取"或"后漏检 0%。该结论以真实引擎为判据得出，非合成掩膜。
- **PL 侧工程**：CDC 违规从 9 条（WNS −3.79 ns，跨 `clk_fpga_1 → clk_fpga_0`）修复至 0 条；资源占用 LUT 11.6%、BRAM 16.1%，时序余量 WNS +0.100 ns。

**在研与未完成（如实说明）**

- **双目第二路采集通路**：已完成引脚核查、资源测算与精度分析——在 60 mm 基线与 150 mm 工作距离下，深度分辨率约 0.02–0.5 mm，**对装配级三维（元件高度、缺件、翘曲）有效，对微米级划痕深度无效**；且镜面高光会破坏焊点处的立体匹配。据此在本次交付周期内优先保障单目主线的可信度。
- **电容触摸多模式切换**：I2C 通路已在设计中，PS 侧驱动未完成。
- **自研 CNN 加速器**（64×64 灰度 → 2 类，单次推理 4.813 ms，经 200/200 逐位一致性验证）在独立工程中完成，**尚未集成进本次板级设计**。

**随作品提交的技能包**

57 条结构化踩坑清单（每条含触发条件、排查步骤与真实代价），覆盖工具链、测量判据与 Block Design 三类反复出现的失败；另含一套**面向 Zynq/PYNQ 的缓存与 DMA 一致性通用技能**，不与本题目绑定。

## 为什么这样改（给你看的，粘贴时删掉）

原稿（截图里那段）与已做内容的差距：

| 原稿承诺 | 实际 | 本稿处理 |
|---|---|---|
| 双目 OV5640 采集 | 只做单目 | **移入"在研与未完成"，并给出量化依据** |
| 电容触摸 | 未做 | 同上，明确"I2C 通路已有、驱动未完成" |
| OSD 叠加引擎 | 软件画 panel + 红框，无 OSD IP | **删掉"OSD 引擎"的说法**，避免被追问 |
| RGB 转灰度 / 背光轮廓提取 / 色彩阈值分割 | 未确认在 PL 里 | **删掉**，只保留确认做过的 |
| 端到端延迟显示 | 有相位计时，非端到端显示 | 改为"**相位计时逐段可测**"并给出实测数字 |
| 三态输出 | ✅ **真正做出来且有实测** | **提到核心主张的位置**，配合"看不清就不能判" |

**改动原则**：**把"计划/拟"换成"已实现并有实测支撑"，把没做的如实归类。**
赛题评价里"文档质量与可复现性"占 15 分，而**如实说明比夸大更容易得分**——
尤其在有实测数据可对照的情况下。
