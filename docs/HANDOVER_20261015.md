## 六、复现方式

```cmd
:: CNN 的 HLS 全流程
cd dl\hls
set TS_HLS_MODE=csim   && run_hls_nopipe.bat -f run_hls.tcl
set TS_HLS_MODE=csynth && run_hls_nopipe.bat -f run_hls.tcl
run_hls_nopipe.bat -f export_ip.tcl

:: BD 集成（按顺序）
cd ps_fft_dual
vivado -mode batch -source cnn_integrate.tcl     :: CNN（含失败被 catch 吞掉的地址分配）
vivado -mode batch -source dwc_fix.tcl           :: 加回位宽转换器
vivado -mode batch -source addr_fix2.tcl         :: **用对象形式分配地址**（关键）
vivado -mode batch -source stereo_stage2.tcl     :: 双路 + axi_iic + GPIO 扩位
vivado -mode batch -source stereo_regslice.tcl   :: 切断组合环
vivado -mode batch -source stereo_portdir.tcl    :: 端口方向对齐
python ..\dl\add_stereo_xdc.py                   :: 16 条引脚约束
python ..\dl\add_vestigial_xdc.py                :: 3 条残留端口 LOC
vivado -mode batch -source cnn_build.tcl         :: 构建

:: 上板自检
xsdb ps_cnn_selftest.tcl
```
