# 成像可信度 → 三态判定（2026-10-19，离线完成）

> 这就是"可信"的正解：**先判断"看清了没有"，再判"工件好不好"**。
> 全部在电脑上用真实帧完成，不需要板子。脚本：`dl/credibility.py`

## 1. 可信度由六个可测量构成

| 指标 | 含义 | 良品实测 |
|---|---|---|
| `mean` | 板区平均亮度 | 110.4 |
| `clip_pm` | 板区饱和像素千分比 | 24.9（焊盘高光） |
| `contrast` | 板区亮度标准差 | 56.9 |
| `sharp` | 板区 \|Laplacian\| 均值（对焦） | 9.14 |
| `match` | 与模板的归一化相关（参考图案在位） | 1.00 |
| `cover` | 板区面积 / 模板面积（工件在位、尺度） | 1.00 |
| `resid` | **对齐后**残余 RMS（旋转/失配） | 0.00 |

**阈值**（阈值旁边写了余量，全部来自实测而不是拍脑袋）：
`mean ∈ [45,205]`、`clip ≤ 60‰`、`contrast ≥ 18`、`sharp ≥ 6`、`match ≥ 0.80`、
`cover ∈ [0.70,1.45]`、`resid ≤ 6`。

## 2. 验证：人为退化 + 一个必须被接受的良性扰动

| 用例 | 结果 | 拒绝原因 |
|---|---|---|
| 良品帧 | **可判** | — |
| 变暗 ×0.35 | 无法判定 | 对比度 12.9 < 18 |
| 变亮 ×1.8 | 无法判定 | 过曝 145‰ > 60 |
| 模糊 σ=2 | 无法判定 | 失焦 1.2 < 6 |
| 噪声 σ=12 | 无法判定 | 残余 30.5 > 6 |
| 旋转 1.5° | 无法判定 | 失焦 5.4 < 6（旋转未被配准吸收） |
| 空场景 | 无法判定 | 过暗 0 < 45 |
| **平移 30 px** | **可判** ✅ | —（平移由质心对齐吸收，**不应**被拒） |

**六种真实退化 100% 被拒；一个良性平移 100% 被接受。**

## 3. 标定过程中修掉的两个错误（都记下来）

1. **`clip ≤ 25‰` 会把好帧判死**：良品实测就是 **24.9‰**（焊盘高光）。改成 60‰。
2. **"平移 30 px" 一开始被拒**：因为残余是在**未对齐**的图像上算的；
   而且用整幅相关做对齐会被大片暗背景主导（残余 13.6 而不是 0）。
   ⇒ 改成**按板区质心对齐**，残余归零，平移被正确接受。

## 4. 三态与判定的连接

```
可信度不通过  →  UNKNOWN（附原因），板端保持停带，绝不沿用上一次结果
可信度通过    →  才允许用差分结果给 OK / NG
```

这套逻辑与 `ps_ui/verdict.c` 的规则一致（UNKNOWN 不是 PASS、超时不是 PASS、错 job_id 拒绝）。

## 5. 边界（如实）

- 只用了**一帧**良品、**一种**光照；阈值是单点标定，不是统计标定；
- 退化用例是**合成**的（变暗/变亮/模糊/噪声/旋转/空场），不是真实故障；
- 旋转 1.5° 被拒的原因落在"失焦"上（sharp 5.4），说明**指标之间会互相顶替**，
  真实部署应把"哪个指标触发"也记录下来（现已输出 reason）；
- 未在板上实现（PS 已有 mean/clip/focus 的采集能力，需按本文件把六个指标凑齐）。
